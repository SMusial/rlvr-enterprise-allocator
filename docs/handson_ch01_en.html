🧮 Markov Decision Process (MDP)

An MDP is a tuple $(S, A, P, R, \gamma)$ where every decision depends only on the current state — the Markov property.
ComponentSymbolWarsaw ASP meaning
State space$S$Technician positions, order status, skills
Action space$A$Assign $T_i$ to $W_j$ — up to $5 \times 20 = 100$ actions
Transition$P(s'|s,a)$Stochastic: SLA depends on distance + skill + urgency
Reward$R(s,a,s')$SLA met / skill match / distance penalty
Discount$\gamma \in [0,1]$Future rewards worth less (default 0.95)

Discounted Return

$$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$$
$G_0$ = total discounted return from step 0 = quality of the entire episode.

Computed backward after episode ends (Monte Carlo):
$$G_{n-1} = R_{n-1}, \qquad G_t = R_t + \gamma\, G_{t+1}$$
⚠️ $G_t$ is NOT monotonically decreasing — if $R_t > 0$ then $G_t > G_{t+1}$; if $R_t < 0$ then $G_t < G_{t+1}$.

Numerical Example

$$G_0 = 10 + 0.95 \cdot (-5) + 0.95^2 \cdot 10 = 10 - 4.75 + 9.025 = 14.275$$

ε-Greedy Policy

$$\pi(a \mid s) = \begin{cases} \text{random action} & \text{with probability } \varepsilon \\[8pt] \displaystyle\arg\max_{a} Q(s,a) & \text{with probability } 1 - \varepsilon \end{cases}$$
With probability $\varepsilon$: random action (exploration)
With probability $1-\varepsilon$: best known action (exploitation)
Value of $\varepsilon$BehaviourWhen to use
1.0Always randomCh01 baseline (fixed, slider disabled)
0.550/50Mid training
0.1Mostly exploitLate training (Ch06+)

Reward Function

$$R = \begin{cases} +2.0 - 0.05\,d & \text{SLA met (skill match + within distance threshold)} \\[6pt] +0.5 - 0.05\,d & \text{skill match, SLA breached (too far)} \\[6pt] -1.0 - 0.02\,d & \text{skill mismatch (regardless of distance)} \end{cases}$$
$d$ = distance in km (Haversine formula). SLA is met when skill matches AND distance is within the order's threshold.

📊 Reward per Step Chart

Green bar = positive reward: SLA met (skill match + close enough)
Red bar = penalty: SLA breach or skill mismatch
Yellow bar = currently selected step

With random policy and 80% skill match bias, expect ~60–70% green bars.

📉 Discounted Return $G_t$ Chart

$G_0$ (step 0) = total episode return — the most important value.

$G_t$ is NOT monotonically decreasing: $$G_t = R_t + \gamma\, G_{t+1}$$ If $R_t > 0$: $G_t > G_{t+1}$.    If $R_t < 0$: $G_t < G_{t+1}$.

$G_t$ is computed offline (backward after episode ends) — Monte Carlo approach. Online updates start in Ch06.

Task 1 — Compute $G_0$

Episode rewards: $R_0=+2.1,\; R_1=-1.2,\; R_2=+1.8,\; R_3=-0.5,\; R_4=+2.3$. $\gamma=0.95$. Compute $G_0$.

💡 Show answer
$$G_4 = R_4 = 2.3$$
$$G_3 = -0.5 + 0.95 \times 2.3 = 1.685$$
$$G_2 = 1.8 + 0.95 \times 1.685 = 3.401$$
$$G_1 = -1.2 + 0.95 \times 3.401 = 2.031$$
$$G_0 = 2.1 + 0.95 \times 2.031 = \mathbf{4.029}$$

Task 2 — Why is $G_t$ not monotonically decreasing?

Episode: $G_0=-25.1,\; G_1=-33.7,\; G_2=-28.9$. Explain why $G_1 < G_0$ and $G_2 > G_1$.

💡 Show answer
$$G_t = R_t + \gamma\, G_{t+1}$$
$G_1 < G_0$: $R_0$ is positive (SLA met). $G_0 = R_0 + \gamma G_1 > \gamma G_1 \approx G_1$.

$G_2 > G_1$: $R_1$ is negative (SLA breach). $G_1 = R_1 + \gamma G_2 < \gamma G_2 \approx G_2$.

Task 3 — MDP components

Identify the 5 MDP components $(S, A, P, R, \gamma)$ for the Warsaw ASP dispatch problem.

💡 Show answer
$S$ — States: dispatch situation (technician positions, order status, skills)
$A$ — Actions: assign $T_i$ to $W_j$ ($5 \times 10 = 50$ possible actions)
$P$ — Transition: $P(s'|s,a)$ — stochastic (SLA depends on distance + skill + urgency)
$R$ — Reward: $+2-0.05d$ (SLA met), $+0.5-0.05d$ (skill match only), $-1-0.02d$ (mismatch)
$\gamma$ — Discount factor: 0.95

Task 4 — Why no learning in Ch01?

Explain why the Learning Curve in Ch01 shows no upward trend despite running 30 episodes.

💡 Show answer
1. $Q=0$ always: The Q-table is never updated. No Bellman update, no TD error.

2. $\varepsilon=1.0$ fixed: Always random. Exploitation never happens.

3. Episodes are independent: Each episode starts fresh with $Q=0$. No information carried between episodes.

Q-table learning starts in Ch06. Value-based planning starts in Ch02.

Task 5 — Technician movement

$T_2$ starts at $(21.05,\; 52.21)$. Step 2: $T_2 \to W_4$ at $(21.08,\; 52.19)$. Step 7: $T_2 \to W_9$ at $(21.02,\; 52.24)$. What is $T_2$'s starting position for step 7?

💡 Show answer
After step 2, $T_2$ moves to $W_4$'s location: $\mathbf{(21.08,\; 52.19)}$.

For step 7, $T_2$ starts from $\mathbf{(21.08,\; 52.19)}$ — not the original starting position.

Technicians accumulate travel distance throughout the shift. A good dispatcher (Ch02+) minimises total travel by assigning nearby technicians.
