❓ What is Chapter 01?

Ch01 is the starting point of the entire RL course. There is no learning — the agent acts randomly. This is the pure MDP baseline.

What happens in the Rust engine?

The function run_ch01_episode() in ch01_mdp.rs:
  1. Generates 5 random technicians and N orders on the Warsaw map
  2. Selects a technician via ε-greedy policy (Q=0 → always random)
  3. Computes reward $R_t$ based on skill match, distance, and urgency
  4. Computes discounted return $G_t$ for the full episode
  5. Returns full MDP trace: $(S_t, A_t, R_t, G_t, \text{explored})$
Ch01 does NOT:
  • ❌ Update Q — Q=0 throughout the entire episode
  • ❌ Use Bellman — activates in Ch02
  • ❌ Learn between episodes
Ch01 DOES:
  • ✅ Establish the MDP formalism for all future chapters
  • ✅ Generate the baseline $G_t$ to compare against Ch02+
  • ✅ Visualise the Warsaw dispatch map
  • ✅ Show the full Glass-Box MDP trace

🧮 Markov Decision Process (MDP)

ComponentSymbolMeaning in Warsaw ASP
State spaceSCurrent operational situation of the dispatch centre
Action spaceAWhich technician to send to which order
Transition modelP(s'|s,a)Probability of the next state given (s,a)
Reward functionR(s,a)Immediate feedback after dispatch decision
Discount factorγHow much we value future rewards vs immediate

Discounted Return $G_t$

$$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$$
Example (γ=0.95, 3 steps): $R_1=10$, $R_2=-5$, $R_3=10$
$$G_0 = 10 + 0.95 \cdot (-5) + 0.95^2 \cdot 10 = 10 - 4.75 + 9.025 = 14.275$$

ε-Greedy Policy

$$\pi(s) = \begin{cases} \text{random action} & \text{with probability } \varepsilon \\ \arg\max_a Q(s,a) & \text{with probability } 1 - \varepsilon \end{cases}$$
With probability ε: random action (exploration)
With probability 1−ε: best known action (exploitation)
Value of εBehaviourWhen to use
1.0Always randomStart of training (Ch01)
0.550/50Mid training
0.1Mostly exploitLate training
0.0Always greedyEvaluation only

Why Bellman is greyed out in Ch01

The Bellman update requires $P(s'|s,a)$ — the transition model. In Ch01 we only observe $(S_t, A_t, R_t)$ without building a model. Bellman activates in Ch02 where we construct $P$ analytically.

Task 1 — Manual discounted return

An episode has 4 steps with rewards: $R_1=8$, $R_2=-3$, $R_3=6$, $R_4=4$. γ=0.95.
Compute $G_0$, $G_1$, $G_2$, $G_3$ manually.

💡 Show answer
$$G_3 = R_4 = 4.0$$
$$G_2 = R_3 + \gamma G_3 = 6 + 0.95 \cdot 4 = 6 + 3.8 = \mathbf{9.8}$$
$$G_1 = R_2 + \gamma G_2 = -3 + 0.95 \cdot 9.8 = -3 + 9.31 = \mathbf{6.31}$$
$$G_0 = R_1 + \gamma G_1 = 8 + 0.95 \cdot 6.31 = 8 + 5.99 = \mathbf{13.99}$$

Task 2 — MDP components identification

For the dispatch: "Technician T2 (skill=plumbing, at Wola) is sent to Order W5 (skill=plumbing, at Mokotow, urgency=0.9)"
Identify: $S_t$, $A_t$, $R_t$ components, and what $S_{t+1}$ might be.

💡 Show answer
$S_t$: Current dispatch centre state — T2 available, W5 pending with high urgency
$A_t$: Assign T2 to W5
$R_t$ components: $R_{base}=+5$, $R_{skill}=+3$ (plumbing match), $R_{distance}=-2$ (Wola→Mokotow ~5km), $R_{urgency}=-1$ (moderate delay)
$R_t \approx +5$
$S_{t+1}$: T2 now busy, W5 assigned — fewer available technicians

Task 3 — ε-greedy decision

Q-table has Q(S2,T0)=0, Q(S2,T1)=0, Q(S2,T2)=0. ε=0.3.
What is the probability that the agent selects T1? What if Q(S2,T2)=5.0?

💡 Show answer
Case 1 — all Q=0:
$$P(T1) = \varepsilon \cdot \frac{1}{3} + (1-\varepsilon) \cdot \frac{1}{3} = \frac{1}{3} \approx 0.333$$
All actions equally likely regardless of ε when Q values are tied.

Case 2 — Q(S2,T2)=5.0:
$$P(T1) = \varepsilon \cdot \frac{1}{3} = 0.3 \cdot \frac{1}{3} = \mathbf{0.1}$$
T1 only chosen during exploration. T2 is always chosen during exploitation.

Task 4 — Why Bellman is greyed out

The Bellman update is: $Q(s,a) \leftarrow Q(s,a) + \alpha [R + \gamma \max_{a'} Q(s',a') - Q(s,a)]$
Why can't we apply this in Ch01? What is missing?

💡 Show answer
Ch01 is missing two things needed for Bellman:

1. No model: We don't know $P(s'|s,a)$ — we only observe the next state after taking the action. Ch02 builds $P$ analytically.

2. No learning rate α: Ch01 doesn't update Q at all. Q=0 throughout. The Bellman update would change nothing because every update is immediately overwritten on the next call.

Ch02 introduces Value Iteration which computes $V^*(s)$ using the known model $P(s'|s,a)$.

Task 5 — Baseline comparison

You run Ch01 with seed=42 and get $G_0 = 12.4$. After implementing Ch02 (Value Iteration), $G_0 = 31.7$.
What is the improvement? Is Ch01 a fair baseline?

💡 Show answer
$$\text{Improvement} = \frac{G_0^{Ch02} - G_0^{Ch01}}{|G_0^{Ch01}|} \times 100 = \frac{31.7 - 12.4}{12.4} \times 100 = \mathbf{+155\%}$$
Is Ch01 a fair baseline? Yes, because:
• Both use the same environment (same technicians, orders, reward function)
• Both use the same γ and seed
• Ch01 represents the best possible random policy — no cherry-picking
The improvement shows the value of model-based planning.
