🧮 Bellman Optimality Equation

$$V^*(s) = \max_{a} \sum_{s'} P(s'|s,a)\,\left[R(s,a) + \gamma \cdot V^*(s')\right]$$
Co oznacza każdy składnik:
  • V*(s) — optymalna długoterminowa wartość stanu s
  • maxa — wybierz akcję maksymalizującą wartość
  • P(s'|s,a) — prawdopodobieństwo przejścia do s' z (s,a)
  • R(s,a) — natychmiastowa nagroda za akcję a w stanie s
  • γ · V*(s') — zdyskontowana przyszła wartość następnego stanu

Algorytm Iteracji Wartości

1
Inicjalizuj V(s) = 0 dla wszystkich stanów
2
For each s: V(k+1)(s) = maxa ∑s' P(s'|s,a) · [ R(s,a) + γ · V(k)(s') ]
3
Compute δ = maxs | V(k+1)(s) − V(k)(s) |
4
Update V ← V(k+1)
5
Jeśli δ < θ → STOP. W przeciwnym razie idź do kroku 2.
6
Wyodębnij politykę: π*(s) = argmaxa ∑s' P(s'|s,a) · [ R(s,a) + γ · V*(s') ]

Twierdzenie o kontrakcji

Operator Bellmana T jest γ-kontrakcją:
$$\|\mathcal{T}V - \mathcal{T}V'\|_\infty \leq \gamma \cdot \|V - V'\|_\infty$$
Dlatego VI zbiega do jedynego punktu stałego V*. Krzywa zbieżności w UI pokazuje tę kontrakcję w działaniu.

solve_exact() — Rozkład LU

Dla ustalonej polityki π:
$$V^\pi = (I - \gamma P^\pi)^{-1}\, r^\pi$$
Implemented in solve_exact() in ch02_bellman.rs przez nalgebra LU.
Użyj gdy |S| ≤ 1000. Unikaj gdy |S| > 10 000 (cost O(|S|3)).

📊 Interpreting the results

📊 Value Function Chart V*(s)

Osie:
• Oś X: stany operacyjne S0–S7 (od najlepszego do najgorszego)
• Oś Y: optymalna długoterminowa wartość V*(s) — wyższa = lepsza

Cel: Pokazuje jak "cenny" jest każdy stan operacyjny z perspektywy długoterminowej.

Na co zwrócić uwagę:
• S0 powinien mieć najwyższą wartość — najlepsza sytuacja
• S7 powinien mieć najniższą wartość — naruszenie SLA bliskie
• Różnica V*(S0) − V*(S7) rośnie z γ — higher γ = agent values good states more

📉 Convergence Curve ||ΔV||∞

Osie:
• Oś X: numer iteracji Bellmana (0, 1, 2, …)
• Oś Y: maksymalna zmiana wartości ||V(k+1) − V(k)||∞ (log scale)

Cel: Pokazuje jak szybko algorytm zbiega do V*. Każda iteracja redukuje błąd o czynnik γ.

Na co zwrócić uwagę:
• Krzywa powinna być monotonicznie malejąca — jeśli nie, błąd implementacji
• Slope ≈ log(γ) — higher γ = slower convergence
• Płaska krzywa = konwergencja osiągnięta — δ < θ

Osie:
• X-axis: dispatch actions A0–A3
• Y-axis: operational states S0–S7
• Kolor komórki: wartość nagrody R(s,a) — zielony = wysoka, czerwony = niska

Cel: Wizualizuje macierz nagród — które kombinacje (stan, akcja) są opłacalne.

Na co zwrócić uwagę:
• Kolumna A1 powinna być najjaśniejsza — dopasowanie daje najwyższą nagrodę
• Kolumna A3 w S6/S7 powinna być najciemniejsza — kary −8 i −10
• Wiersz S1 powinien być jaśniejszy niż S0 — pilność zwiększa nagrodę

Zadanie 1 — Ręczna iteracja Bellmana

You have 2 states (S0, S7) and 1 action. R(S0,A0)=8, R(S7,A0)=1. P(S0|S0,A0)=0.9, P(S7|S0,A0)=0.1. P(S0|S7,A0)=0.2, P(S7|S7,A0)=0.8. γ=0.9. Perform 2 Bellman iterations manually starting from V(S0)=V(S7)=0.

💡 Pokaż odpowiedź
Iteracja 1:
$$V^{(1)}(S_0) = 8 + 0.9\cdot(0.9\cdot 0 + 0.1\cdot 0) = \mathbf{8.0}$$
$$V^{(1)}(S_7) = 1 + 0.9\cdot(0.2\cdot 0 + 0.8\cdot 0) = \mathbf{1.0}$$
Iteracja 2:
$$V^{(2)}(S_0) = 8 + 0.9\cdot(0.9\cdot 8 + 0.1\cdot 1) = \mathbf{14.57}$$
$$V^{(2)}(S_7) = 1 + 0.9\cdot(0.2\cdot 8 + 0.8\cdot 1) = \mathbf{3.16}$$

Zadanie 2 — Wyznacz optymalną politykę

For state S1 you have V*(S0)=50, V*(S7)=10.
A0: P(S0|S1,A0)=0.6, P(S7|S1,A0)=0.4, R(S1,A0)=6
A1: P(S0|S1,A1)=0.8, P(S7|S1,A1)=0.2, R(S1,A1)=9
γ=0.95. Which action is optimal?

💡 Pokaż odpowiedź
$$Q(S_1,A_0) = 6 + 0.95\cdot(0.6\cdot 50 + 0.4\cdot 10) = \mathbf{38.3}$$
$$Q(S_1,A_1) = 9 + 0.95\cdot(0.8\cdot 50 + 0.2\cdot 10) = \mathbf{48.9}$$
Optymalna akcja: A1 since Q(S1,A1) > Q(S1,A0)

Zadanie 3 — Wpływ γ na politykę

For state S4:
A0: R=3, leads to S2 (V*=40) with p=0.7 and S5 (V*=15) with p=0.3
A2: R=4, leads to S3 (V*=35) with p=0.9 and S6 (V*=8) with p=0.1
Compute Q(S4,A0) and Q(S4,A2) for γ=0.99 and γ=0.5. Does the policy change?

💡 Pokaż odpowiedź
γ=0.99:
$$Q(S_4,A_0) = 3 + 0.99\cdot(0.7\cdot 40 + 0.3\cdot 15) = \mathbf{35.175}$$
$$Q(S_4,A_2) = 4 + 0.99\cdot(0.9\cdot 35 + 0.1\cdot 8) = \mathbf{35.977}$$
Optymalna: A2

γ=0.5:
$$Q(S_4,A_0) = 3 + 0.5\cdot 32.5 = \mathbf{19.25}$$
$$Q(S_4,A_2) = 4 + 0.5\cdot 32.3 = \mathbf{20.15}$$
Optymalna: A2 (ta sama polityka, mniejsza różnica)

Zadanie 4 — Weryfikacja kontrakcji

In the Glass-Box you see:
Iteracja 1: max ΔV = 8.0
Iteracja 2: max ΔV = 7.2
Iteracja 3: max ΔV = 6.48
What is the value of γ? Is the contraction theorem satisfied?

💡 Pokaż odpowiedź
$$\gamma = \frac{\delta_2}{\delta_1} = \frac{7.2}{8.0} = \mathbf{0.9}$$
Verification: δ3 / δ2 = 6.48 / 7.2 = 0.9 ✔
Twierdzenie o kontrakcji jest spełnione: każda iteracja redukuje błąd o czynnik γ=0.9.

Zadanie 5 — Kiedy użyć LU zamiast VI?

You have an ASP system with 50 states and 10 actions. VI needs 500 iterations to converge. Compare the computational cost of VI vs LU decomposition.

💡 Pokaż odpowiedź
$$\mathcal{O}(|S|^2 \cdot |A| \cdot T) = \mathcal{O}(12{,}500{,}000)$$
$$\mathcal{O}(|S|^3) = \mathcal{O}(50^3) = \mathcal{O}(125{,}000)$$
Wniosek: Dla 50 stanów LU jest ~100x szybsze. Użyj LU gdy |S| ≤ 1000.
For |S| = 10,000: LU = O(1012) — too slow. Use VI instead.
