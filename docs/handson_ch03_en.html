❓ What is Chapter 03?

Ch03 introduces the Multi-Armed Bandit — the simplest RL problem. No states, no transitions, just repeated action selection with stochastic rewards.

What happens in the Rust engine?

The function run_ch03_bandits() in ch03_bandit.rs:
  1. Creates 5 arms with fixed true SLA rates (unknown to agent)
  2. Runs ε-Greedy, UCB1, and Thompson Sampling simultaneously
  3. Each algorithm pulls an arm, observes reward (1=SLA met, 0=breached)
  4. Updates Q-values / posteriors after each pull
  5. Returns full trace: arm pulled, reward, regret, cumulative regret, ε, mode

🧮 Regret

$$\text{Regret}(T) = \sum_{t=1}^{T} \left[ \mu^* - \mu_{a_t} \right]$$
$\mu^* = \max_a \mu_a$ = optimal arm true SLA rate. Regret measures the cost of not always picking the best arm.

ε-Greedy with Annealing

$$\varepsilon_t = \max\left(\varepsilon_{\min},\ \frac{\varepsilon_0}{1 + \alpha t}\right)$$
$$Q(a) \leftarrow Q(a) + \frac{1}{N(a)} \left[ R - Q(a) \right]$$
Incremental mean update. Starts with high exploration, gradually shifts to exploitation. Implemented in epsilon_greedy_select() in ch03_bandit.rs.

UCB1 (Upper Confidence Bound)

$$\text{UCB}(a) = Q(a) + c \sqrt{\frac{\ln t}{N(a)}}$$
$Q(a)$ = exploitation term. $c\sqrt{\ln t / N(a)}$ = uncertainty bonus. Arms pulled rarely have high uncertainty → get explored more. Regret bound: $O(\sqrt{KT \ln T})$. Implemented in ucb_select().

Thompson Sampling

$$\theta_a \sim \text{Beta}(\alpha_a, \beta_a)$$
Prior: Beta(1,1) = uniform. After each pull: if reward=1 → $\alpha_a += 1$, if reward=0 → $\beta_a += 1$. At each step: sample $\theta_a$ from each posterior, pick $\arg\max_a \theta_a$. Implemented in thompson_select().

📊 Interpreting the results

📈 Cumulative Regret Chart

Axes: X = step number, Y = cumulative regret
Purpose: Shows how much value each algorithm lost by not always picking the best arm.
What to watch:
• Thompson Sampling should have the lowest regret after many steps
• UCB1 is deterministic — same result every run with same seed
• ε-Greedy regret grows faster if ε stays high

🎰 Arm Pull Distribution

Purpose: Shows how many times each skill slot was selected.
What to watch:
• Plumbing (arm 2) should dominate after convergence
• UCB1 explores all arms early, then concentrates on best
• Thompson Sampling concentrates fastest on the best arm

📊 Q-value Convergence

Purpose: Shows how well each algorithm estimates the true SLA rates.
What to watch:
• Dashed lines = true SLA rates (hidden from agent)
• Solid bars = learned Q(a) estimates
• Good convergence = bars close to dashed lines

Task 1 — Regret calculation

In 3 steps, the agent pulled: arm0 (HVAC, $\mu$=0.72), arm2 (Plumbing, $\mu$=0.88), arm1 (Electrical, $\mu$=0.65). Compute regret for each step and total regret.

💡 Show answer
$$\text{Regret}_1 = 0.88 - 0.72 = 0.16$$
$$\text{Regret}_2 = 0.88 - 0.88 = 0.00$$
$$\text{Regret}_3 = 0.88 - 0.65 = 0.23$$
$$\text{Total Regret} = 0.16 + 0.00 + 0.23 = \mathbf{0.39}$$

Task 2 — UCB value calculation

At step t=100: Q(arm2)=0.85, N(arm2)=60, c=2.0. Compute UCB(arm2).

💡 Show answer
$$\text{UCB}(arm2) = 0.85 + 2.0 \cdot \sqrt{\frac{\ln 100}{60}} = 0.85 + 2.0 \cdot \sqrt{\frac{4.605}{60}} = 0.85 + 2.0 \cdot 0.277 = \mathbf{1.404}$$

Task 3 — Thompson Sampling posterior

Arm 2 (Plumbing) has been pulled 10 times: 8 successes, 2 failures. What is the posterior distribution? What is the mean of the posterior?

💡 Show answer
Prior: Beta(1,1). After 8 successes and 2 failures:
$$\theta_{arm2} \sim \text{Beta}(1+8,\ 1+2) = \text{Beta}(9, 3)$$
$$\mathbb{E}[\theta_{arm2}] = \frac{9}{9+3} = \frac{9}{12} = \mathbf{0.75}$$
The true rate is 0.88 — more pulls will shift the posterior closer to the true value.

Task 4 — ε-Greedy annealing

Initial ε=0.5, decay α=0.01. What is ε at step t=50? At t=200?

💡 Show answer
$$\varepsilon_{50} = \frac{0.5}{1 + 0.01 \cdot 50} = \frac{0.5}{1.5} = \mathbf{0.333}$$
$$\varepsilon_{200} = \frac{0.5}{1 + 0.01 \cdot 200} = \frac{0.5}{3.0} = \mathbf{0.167}$$

Task 5 — Why Thompson beats UCB on Bernoulli bandits

Both UCB1 and Thompson Sampling achieve $O(\sqrt{KT \ln T})$ regret. Why does Thompson Sampling often outperform UCB1 in practice on Bernoulli bandits?

💡 Show answer
Thompson Sampling naturally incorporates uncertainty via the Beta posterior:

• Arms with few pulls have wide posteriors → high variance → get sampled more
• As evidence accumulates, the best arm's posterior concentrates near its true rate
• UCB1 uses a fixed formula $c\sqrt{\ln t / N(a)}$ which can over-explore in early steps
• Thompson's Bayesian approach adapts more naturally to the Bernoulli reward structure

In practice: Thompson Sampling has lower regret on Bernoulli bandits, UCB1 is more predictable (deterministic).

✅ Pros of Bandit algorithms
  • No model needed — learn from raw pulls
  • Principled exploration-exploitation trade-off
  • Thompson Sampling: near-optimal Bayesian approach
  • UCB1: deterministic, provable regret bound
❌ Limitations
  • No state transitions — cannot model sequential decisions
  • Bernoulli rewards only for Thompson (as implemented)
  • ε and c must be tuned manually
  • Stationary assumption — true rates don't change
