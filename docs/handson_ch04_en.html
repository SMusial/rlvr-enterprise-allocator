🧮 Policy Evaluation

$$V^\pi(s) = \sum_{s'} P(s'|s,\pi(s)) \left[ R(s,\pi(s)) + \gamma V^\pi(s') \right]$$
Iterate until $\|V^{(k+1)} - V^{(k)}\|_\infty < \theta$. Converges to unique $V^\pi$ (contraction mapping). Implemented in policy_evaluation() in ch04_dp.rs.

Policy Improvement

$$\pi'(s) = \arg\max_a \sum_{s'} P(s'|s,a) \left[ R(s,a) + \gamma V^\pi(s') \right]$$
Policy Improvement Theorem: $V^{\pi'}(s) \geq V^\pi(s)$ for all $s$. The new policy is always at least as good.

Policy Iteration

1. Initialise $\pi$ arbitrarily
2. Evaluate: compute $V^\pi$
3. Improve: $\pi' = \text{greedy}(V^\pi)$
4. If $\pi' = \pi$ → STOP. Else $\pi \leftarrow \pi'$, go to 2.

Converges in finite steps. Typically 3–10 outer iterations.

Value Iteration

$$V^{(k+1)}(s) = \max_a \sum_{s'} P(s'|s,a) \left[ R(s,a) + \gamma V^{(k)}(s') \right]$$
Stop when $\|V^{(k+1)} - V^{(k)}\|_\infty < \theta$. Extract policy: $\pi^*(s) = \arg\max_a Q^*(s,a)$.

Asynchronous DP — Bellman Residual

$$\text{Residual}(s) = |V^{(k+1)}(s) - V^{(k)}(s)|$$
States with high residuals are updated first. In ASP: S5 and S7 (critical states) get updated first → faster convergence in crisis scenarios. Implemented in async_value_iteration().

🗺 ASP Environment for DP

DP requires the full model: transition matrix $P(s'|s,a)$ and reward matrix $R(s,a)$. Both are built analytically from the Warsaw ASP specification.
ParameterValueEffect
γ (discount)0.5–0.999Higher = more far-sighted. Start with 0.95.
θ (convergence)1e-3–1e-7Smaller = more precise but more iterations
Seed0–9999Affects random tie-breaking in policy
Key insight: All three algorithms use the same P and R matrices. Any difference in final V*(s) is numerical precision only (<1e-6).

Task 1 — Policy Evaluation step

State S0, policy $\pi(S0)=A1$. Transitions: P(S0|S0,A1)=0.7, P(S1|S0,A1)=0.3. R(S0,A1)=8. $\gamma$=0.9. Current V: V(S0)=10, V(S1)=5. Compute one Bellman expectation update for V(S0).

💡 Show answer
$$V^\pi(S0) = \sum_{s'} P(s'|S0,A1)[R(S0,A1) + \gamma V(s')]$$
$$= 0.7 \cdot [8 + 0.9 \cdot 10] + 0.3 \cdot [8 + 0.9 \cdot 5]$$
$$= 0.7 \cdot 17 + 0.3 \cdot 12.5 = 11.9 + 3.75 = \mathbf{15.65}$$

Task 2 — Policy Improvement

State S3, current V*(s): V(S0)=20, V(S7)=2. Two actions: A0 gives R=5, P(S0|S3,A0)=0.8, P(S7|S3,A0)=0.2. A1 gives R=3, P(S0|S3,A1)=0.9, P(S7|S3,A1)=0.1. $\gamma$=0.95. Which action does policy improvement choose?

💡 Show answer
$$Q(S3,A0) = 5 + 0.95(0.8 \cdot 20 + 0.2 \cdot 2) = 5 + 0.95 \cdot 16.4 = 5 + 15.58 = \mathbf{20.58}$$
$$Q(S3,A1) = 3 + 0.95(0.9 \cdot 20 + 0.1 \cdot 2) = 3 + 0.95 \cdot 18.2 = 3 + 17.29 = \mathbf{20.29}$$
Policy improvement chooses A0 since Q(S3,A0) > Q(S3,A1).

Task 3 — PI vs VI trade-off

PI needs 5 outer iterations, each requiring 50 inner sweeps. VI needs 200 sweeps total. Which is faster? When would PI be preferred?

💡 Show answer
PI total sweeps = 5 × 50 = 250 sweeps > VI's 200 sweeps.

In this case VI is faster. PI is preferred when:
• The policy is the primary output (not just V*)
• Each outer iteration converges quickly (few inner sweeps)
• The state space is small and policy evaluation is cheap

For large state spaces, VI is usually faster in total computation.

Task 4 — Bellman Residual

After one VI sweep: V_old(S5)=8.0, V_new(S5)=11.3. V_old(S2)=15.0, V_new(S2)=15.1. Which state does Async VI update first in the next sweep?

💡 Show answer
$$\text{Residual}(S5) = |11.3 - 8.0| = 3.3$$
$$\text{Residual}(S2) = |15.1 - 15.0| = 0.1$$
Async VI updates S5 first (highest residual = most to gain from update).

Task 5 — Why DP requires a model

Why can't we apply Policy Iteration to the Warsaw ASP without knowing P(s'|s,a)? What would we need instead?

💡 Show answer
Policy Evaluation requires computing:
$$V^\pi(s) = \sum_{s'} P(s'|s,\pi(s)) [R(s,\pi(s)) + \gamma V^\pi(s')]$$
Without $P(s'|s,a)$, we cannot compute this sum. We would need either:
• Monte Carlo (Ch05): estimate $V^\pi$ from sampled episodes
• TD Learning (Ch06): bootstrap from observed transitions
• Model learning (Ch10): learn $\hat{P}(s'|s,a)$ from experience, then apply DP

✅ When to use DP
  • Full model P(s'|s,a) is available
  • State space is discrete and finite
  • Exact optimal policy is required
  • Offline planning (not real-time)
❌ DP limitations
  • Requires full model — not model-free
  • Curse of dimensionality: $O(|S|^2 |A|)$ per sweep
  • Synchronous updates — all states each sweep
  • Not applicable to continuous state spaces
