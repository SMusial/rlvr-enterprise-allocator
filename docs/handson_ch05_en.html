❓ What is Chapter 05?

Ch05 introduces model-free learning. Unlike DP (Ch04), MC methods learn directly from episodes without knowing P(s'|s,a).

🧮 Monte Carlo Return

$$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots = \sum_{k=0}^{T-t-1} \gamma^k R_{t+k+1}$$

First-Visit MC Prediction

$V(s) \leftarrow$ average of $G_t$ for all first visits to $s$ across all episodes.
Unbiased estimator. Converges to $V^\pi(s)$ as episodes $\to \infty$. Implemented in mc_first_visit_prediction().

Every-Visit MC Prediction

$V(s) \leftarrow$ average of $G_t$ for all visits to $s$ across all episodes.
Biased but consistent. More data per episode → lower variance. Implemented in mc_every_visit_prediction().

On-Policy MC Control

1. Generate episode using ε-soft policy
2. For each (s,a) pair (first-visit): $G \leftarrow$ discounted return
3. $Q(s,a) \leftarrow$ average($G$) — incremental update
4. $\pi(s) \leftarrow \arg\max_a Q(s,a)$ — greedy improvement

As $\varepsilon \to 0$, policy converges to optimal greedy policy.

Off-Policy MC with Importance Sampling

$$Q(s,a) \leftarrow Q(s,a) + \frac{W}{C(s,a)} \left[ G - Q(s,a) \right]$$
$W = \pi(a|s) / b(a|s)$ = importance sampling ratio. Behaviour policy $b$ generates episodes. Target policy $\pi$ is what we optimise. Foundation for Q-Learning (Ch06).

Task 1 — Manual MC return

An episode visits state S2 at steps t=1 and t=3. Rewards: $R_2=5, R_3=-2, R_4=8, R_5=3$. $\gamma$=0.9. Compute $G_1$ (return from first visit) and $G_3$ (return from second visit).

💡 Show answer
$$G_3 = R_4 + \gamma R_5 = 8 + 0.9 \cdot 3 = 8 + 2.7 = \mathbf{10.7}$$
$$G_1 = R_2 + \gamma R_3 + \gamma^2 R_4 + \gamma^3 R_5 = 5 + 0.9(-2) + 0.81(8) + 0.729(3)$$
$$= 5 - 1.8 + 6.48 + 2.187 = \mathbf{11.867}$$
First-Visit MC uses $G_1 = 11.867$. Every-Visit MC uses both $G_1$ and $G_3$.

Task 2 — First-Visit vs Every-Visit update

After 3 episodes, state S4 has been visited: episode 1 (first visit, G=12), episode 2 (first visit, G=8, second visit, G=5), episode 3 (first visit, G=10). Compute V(S4) for First-Visit MC and Every-Visit MC.

💡 Show answer
First-Visit MC (only first visit per episode):
Returns: [12, 8, 10] → 3 samples
$$V_{FV}(S4) = \frac{12 + 8 + 10}{3} = \mathbf{10.0}$$
Every-Visit MC (all visits):
Returns: [12, 8, 5, 10] → 4 samples
$$V_{EV}(S4) = \frac{12 + 8 + 5 + 10}{4} = \mathbf{8.75}$$

Task 3 — Why MC is unbiased but high variance

Explain why First-Visit MC is an unbiased estimator of $V^\pi(s)$ but has high variance. How does increasing the number of episodes help?

💡 Show answer
Unbiased: $G_t$ is the exact discounted return from state $s$ under policy $\pi$. Its expectation is exactly $V^\pi(s)$ by definition. No bootstrapping → no bias.

High variance: Each episode produces a different $G_t$ due to stochastic transitions and rewards. A single episode's return can be far from the true mean.

More episodes: By the Law of Large Numbers, the average of many $G_t$ samples converges to $V^\pi(s)$. Variance decreases as $O(1/\sqrt{N})$ where $N$ = number of visits.

Task 4 — Importance Sampling ratio

Behaviour policy $b$: uniform random, $b(A1|S3) = 0.25$. Target policy $\pi$: greedy, $\pi(A1|S3) = 1.0$. Compute the IS ratio $W = \pi(A1|S3) / b(A1|S3)$. What happens to the IS ratio if the episode has 5 steps all with the same action?

💡 Show answer
$$W = \frac{\pi(A1|S3)}{b(A1|S3)} = \frac{1.0}{0.25} = \mathbf{4.0}$$
For 5 steps all with the same action:
$$W_{total} = \prod_{t=1}^{5} \frac{\pi(a_t|s_t)}{b(a_t|s_t)} = 4.0^5 = \mathbf{1024}$$
This is the IS variance explosion problem — the ratio grows exponentially with episode length.

Task 5 — MC vs DP: when to use each

You have a Warsaw ASP environment. When would you use MC (Ch05) instead of DP (Ch04)?

💡 Show answer
Use MC (Ch05) when:
• P(s'|s,a) is unknown — you can only observe transitions
• The environment is too complex to model analytically
• You want to learn from real dispatch logs (historical data)
• The state space is large and you only visit a subset of states

Use DP (Ch04) when:
• P(s'|s,a) is known exactly (as in the Warsaw ASP analytical model)
• You need the exact optimal policy, not an approximation
• The state space is small enough for full sweeps
