❓ What is Chapter 06?

Ch06 introduces Temporal Difference Learning — the combination of MC (model-free) and DP (bootstrapping). TD updates after every step using current estimates.

Three TD algorithms

AlgorithmTypeKey property
TD(0)PredictionEstimates $V^\pi$ for a fixed policy
SARSAOn-policy controlLearns value of ε-soft policy (safe)
Q-LearningOff-policy controlDirectly learns $Q^*$ (optimal)
The one-line difference:
SARSA: uses $Q(S', A')$ where $A'$ is chosen by ε-greedy (on-policy)
Q-Learning: uses $\max_{a'} Q(S', a')$ regardless of what action is taken (off-policy)

🧮 TD Error

$$\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)$$
The "surprise" signal — how much better or worse than expected. Positive = better than expected, negative = worse. Implemented in ch06_td.rs.

TD(0) Prediction

$$V(S_t) \leftarrow V(S_t) + \alpha \left[ R_{t+1} + \gamma V(S_{t+1}) - V(S_t) \right]$$
Updates after every step. Converges to $V^\pi$ for any fixed policy $\pi$. Implemented in td0_prediction().

SARSA (On-Policy)

$$Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha \left[ R_{t+1} + \gamma Q(S_{t+1}, A_{t+1}) - Q(S_t, A_t) \right]$$
$A_{t+1}$ is chosen by the same ε-greedy policy. On-policy: learns the value of the ε-soft policy. Conservative — accounts for exploration cost. Implemented in sarsa().

Q-Learning (Off-Policy)

$$Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha \left[ R_{t+1} + \gamma \max_{a'} Q(S_{t+1}, a') - Q(S_t, A_t) \right]$$
Uses $\max_{a'} Q(S_{t+1}, a')$ — the greedy action, regardless of what was actually taken. Off-policy: directly learns $Q^*$. Converges to optimal regardless of behaviour policy. Implemented in q_learning().

SARSA vs Q-Learning — Cliff Walking Analogy

In risky environments (like S7 — SLA breach imminent):
• SARSA walks safely away from the cliff (accounts for accidental falls during ε-exploration)
• Q-Learning walks along the cliff edge (optimal but risky during learning)

In ASP: SARSA is safer during training, Q-Learning finds the better final policy.

Task 1 — TD(0) update

Current V(S3)=10, V(S5)=6. Agent takes action A1 in S3, receives R=4, transitions to S5. α=0.1, γ=0.95. Compute the TD error and new V(S3).

💡 Show answer
$$\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t) = 4 + 0.95 \cdot 6 - 10 = 4 + 5.7 - 10 = \mathbf{-0.3}$$
$$V(S3) \leftarrow 10 + 0.1 \cdot (-0.3) = 10 - 0.03 = \mathbf{9.97}$$
Negative TD error: the transition was worse than expected.

Task 2 — SARSA update

Q(S2,A1)=8, Q(S4,A0)=12. Agent in S2 takes A1, gets R=3, transitions to S4, then chooses A0 (ε-greedy). α=0.1, γ=0.9. Compute new Q(S2,A1).

💡 Show answer
$$\delta_t = R + \gamma Q(S_{t+1}, A_{t+1}) - Q(S_t, A_t) = 3 + 0.9 \cdot 12 - 8 = 3 + 10.8 - 8 = 5.8$$
$$Q(S2,A1) \leftarrow 8 + 0.1 \cdot 5.8 = 8 + 0.58 = \mathbf{8.58}$$

Task 3 — Q-Learning update

Q(S2,A1)=8. Agent in S2 takes A1, gets R=3, transitions to S4. Q(S4,A0)=12, Q(S4,A1)=9, Q(S4,A2)=15. α=0.1, γ=0.9. Compute new Q(S2,A1) using Q-Learning.

💡 Show answer
Q-Learning uses $\max_{a'} Q(S4, a') = \max(12, 9, 15) = 15$
$$\delta_t = R + \gamma \max_{a'} Q(S4, a') - Q(S2,A1) = 3 + 0.9 \cdot 15 - 8 = 3 + 13.5 - 8 = 8.5$$
$$Q(S2,A1) \leftarrow 8 + 0.1 \cdot 8.5 = 8 + 0.85 = \mathbf{8.85}$$
Note: Q-Learning gives a higher update than SARSA (Task 2) because it uses the greedy max.

Task 4 — Why SARSA is safer in S7

In state S7 (SLA breach imminent), SARSA chooses A0 (dispatch nearest) while Q-Learning chooses A1 (dispatch skill-matched). Explain why SARSA is more conservative here.

💡 Show answer
SARSA accounts for the exploration cost in its Q estimates:

• With ε=0.3, there's a 30% chance of taking a random action in S7
• SARSA's Q(S7,A1) is lower because it includes the expected cost of accidentally taking a bad action during exploration
• Q-Learning's Q(S7,A1) is higher because it always uses $\max_{a'} Q$ — ignoring exploration

In S7, the penalty for a wrong action is very high (−8 to −10). SARSA's conservative estimate leads it to prefer the safer A0.

Task 5 — TD vs MC: key trade-off

TD(0) is biased (bootstrapping) but has lower variance than MC. Explain this bias-variance trade-off and when you would prefer TD over MC.

💡 Show answer
TD bias: TD uses $V(S_{t+1})$ as a proxy for the true future return. If $V$ is wrong (early in training), the TD target is biased.

MC variance: MC uses the actual return $G_t$ which depends on all future random transitions. High variance, especially for long episodes.

Prefer TD when:
• Episodes are long or continuing (MC must wait for episode end)
• You need online updates (real-time dispatch decisions)
• Lower variance is more important than unbiasedness

Prefer MC when:
• Episodes are short
• Unbiased estimates are critical
• You have historical episode data to learn from
