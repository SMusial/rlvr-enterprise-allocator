🧮 n-Step TD Return

$$G_t^{(n)} = R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{n-1} R_{t+n} + \gamma^n V(S_{t+n})$$
$$V(S_t) \leftarrow V(S_t) + \alpha \left[ G_t^{(n)} - V(S_t) \right]$$
n=1: TD(0) — maximum bootstrapping, minimum variance. n=∞: Monte Carlo — no bootstrapping, maximum variance. n=3–5: sweet spot. Implemented in nstep_td_prediction().

n-Step SARSA

$$G_t^{(n)} = R_{t+1} + \cdots + \gamma^{n-1} R_{t+n} + \gamma^n Q(S_{t+n}, A_{t+n})$$
$$Q(S_t,A_t) \leftarrow Q(S_t,A_t) + \alpha \left[ G_t^{(n)} - Q(S_t,A_t) \right]$$
On-policy: $A_{t+n}$ is chosen by the same ε-greedy policy. Implemented in nstep_sarsa().

Dyna-Q

For each real step:
1. Q-Learning update: $Q(s,a) \mathrel{+}= \alpha[R + \gamma \max_{a'} Q(s',a') - Q(s,a)]$
2. Model update: $\text{Model}(s,a) = (R, s')$
3. Planning (k times): sample random $(s,a)$ from model, do Q-Learning update

With k=5 planning steps, Dyna-Q is ~5x more sample-efficient. Implemented in dyna_q().

Dyna-Q+ Exploration Bonus

$$r' = r + \kappa\sqrt{\tau(s,a)}$$
$\tau(s,a)$ = steps since $(s,a)$ was last tried. Prevents stagnation in changing environments. $\kappa$ controls bonus strength (default: 0.001). Implemented in dyna_q_plus().

Task 1 — n-Step return calculation

3-step return with rewards $R_1=5, R_2=-2, R_3=8$. $V(S_3)=10$, $\gamma$=0.9. Compute $G_0^{(3)}$.

💡 Show answer
$$G_0^{(3)} = R_1 + \gamma R_2 + \gamma^2 R_3 + \gamma^3 V(S_3)$$
$$= 5 + 0.9(-2) + 0.81(8) + 0.729(10) = 5 - 1.8 + 6.48 + 7.29 = \mathbf{16.97}$$

Task 2 — Dyna-Q planning step

Dyna-Q model contains: Model(S2,A1)=(R=6, S4). Q(S2,A1)=8, Q(S4,A0)=15, Q(S4,A1)=12. α=0.1, γ=0.95. Compute one planning update for Q(S2,A1).

💡 Show answer
Planning uses the model: $R=6$, $s'=S4$, $\max_{a'} Q(S4,a') = 15$
$$\delta = R + \gamma \max_{a'} Q(S4,a') - Q(S2,A1) = 6 + 0.95 \cdot 15 - 8 = 6 + 14.25 - 8 = 12.25$$
$$Q(S2,A1) \leftarrow 8 + 0.1 \cdot 12.25 = 8 + 1.225 = \mathbf{9.225}$$

Task 3 — Dyna-Q+ exploration bonus

State-action pair (S5,A2) was last tried 100 steps ago. κ=0.001. What is the exploration bonus added to the reward?

💡 Show answer
$$\text{bonus} = \kappa \sqrt{\tau(S5,A2)} = 0.001 \cdot \sqrt{100} = 0.001 \cdot 10 = \mathbf{0.01}$$
This small bonus encourages the agent to revisit (S5,A2) if it hasn't been tried recently.

Task 4 — Why n=3–5 is the sweet spot

Explain why n=1 (TD0) and n=∞ (MC) are both suboptimal, and why n=3–5 is typically best.

💡 Show answer
n=1 (TD0): Maximum bootstrapping → high bias (estimates depend on current V which may be wrong), but low variance.

n=∞ (MC): No bootstrapping → zero bias, but high variance (full episode return is noisy).

n=3–5 sweet spot: Enough steps to reduce bias (propagates reward signal further back) while keeping variance manageable. The optimal n depends on the environment — longer episodes benefit from larger n.

Task 5 — Dyna-Q sample efficiency

Q-Learning needs 500 episodes to converge. Dyna-Q with k=5 needs 100 episodes. How many real environment interactions does each use? What is the sample efficiency gain?

💡 Show answer
Assume each episode has ~20 steps:
Q-Learning: 500 × 20 = 10,000 real steps
Dyna-Q (k=5): 100 × 20 = 2,000 real steps (+ 2,000 × 5 = 10,000 simulated steps)
$$\text{Sample efficiency gain} = \frac{10{,}000}{2{,}000} = \mathbf{5\times}$$
Dyna-Q uses 5x fewer real interactions. The simulated steps are cheap (model lookup) vs real steps (actual dispatch).
