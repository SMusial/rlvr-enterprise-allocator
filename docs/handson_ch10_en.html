🏢 Business Problem

Warsaw ASP — Learning the Model

In Ch04 we had the exact model P(s'|s,a). In Ch10 the agent learns $\hat{T}(s,a,s')$ and $\hat{R}(s,a)$ from real experience, then uses the learned model for planning. This is the bridge between model-free and model-based RL.

❓ What is Chapter 10?

Ch10 extends Dyna-Q (Ch07) with an explicit World Model object and adds three more sophisticated model-based algorithms.

Four algorithms

AlgorithmKey property
WM Q-LearningDyna-Q with explicit tabular world model
Prioritised SweepingPlan from states with highest $|\delta|$ first
MBPO (PG)Synthetic rollouts for REINFORCE
Uncertainty BonusUCB-style: $Q_{bonus}(s,a) = Q(s,a) + \beta/\sqrt{N(s,a)+1}$

🧮 World Model

$\hat{T}(s,a,s')$ = learned from transition counts. $\hat{R}(s,a)$ = mean observed reward. Planning: k Q-Learning steps on model samples. Implemented in ch10_world_model.rs.

Prioritised Sweeping

$$\text{Priority}(s,a) = |R(s,a) + \gamma \max_{a'} Q(s',a') - Q(s,a)|$$
Plan from highest priority first. Propagate value updates to predecessors after each update. Focuses computation on states that matter most. Implemented in prioritised_sweeping().

MBPO (Model-Based Policy Gradient)

$$G_t^{\text{model}} = \sum_{k=t}^{H} \gamma^{k-t} \hat{R}(s_k, a_k)$$
$$\theta \leftarrow \theta + \alpha \gamma^t G_t^{\text{model}} \nabla \log \pi(a_t|s_t)$$
Real step: collect $(s,a,r,s')$, update model. Synthetic rollout: generate trajectory from model. REINFORCE update on synthetic trajectory. Implemented in mbpo().

Uncertainty Bonus

$$Q_{\text{bonus}}(s,a) = Q(s,a) + \frac{\beta}{\sqrt{N(s,a)+1}}$$
Action selection uses $Q_{\text{bonus}}$. Q update uses standard Q-Learning (no bonus). Encourages exploration of rarely-visited state-action pairs. Implemented in uncertainty_bonus().

Task 1 — World Model update

Agent takes action A1 in state S3, observes reward R=6, transitions to S5. Model currently has: Model(S3,A1) = (R=4, S5, count=3). Update the model.

💡 Show answer
Transition update: $\hat{T}(S3,A1,S5)$ count: 3 → 4. $\hat{T}(S3,A1,S5) = 4/4 = 1.0$ (always S5 so far)
Reward update: $\hat{R}(S3,A1) = \frac{3 \cdot 4 + 6}{4} = \frac{18}{4} = \mathbf{4.5}$ (incremental mean)

Task 2 — Prioritised Sweeping priority

State S5, action A0: Q(S5,A0)=8, R(S5,A0)=3, $\max_{a'} Q(S7,a')=5$, $\gamma$=0.95. Compute the priority for (S5,A0).

💡 Show answer
$$\text{Priority}(S5,A0) = |R(S5,A0) + \gamma \max_{a'} Q(S7,a') - Q(S5,A0)|$$
$$= |3 + 0.95 \cdot 5 - 8| = |3 + 4.75 - 8| = |-0.25| = \mathbf{0.25}$$

Task 3 — Uncertainty bonus

State S4, action A2 has been visited N(S4,A2)=3 times. β=1.0. Compute $Q_{bonus}(S4,A2)$ if Q(S4,A2)=10.

💡 Show answer
$$Q_{\text{bonus}}(S4,A2) = Q(S4,A2) + \frac{\beta}{\sqrt{N(S4,A2)+1}} = 10 + \frac{1.0}{\sqrt{3+1}} = 10 + \frac{1.0}{2} = \mathbf{10.5}$$

Task 4 — MBPO synthetic rollout

MBPO generates a 3-step synthetic rollout from the model: $\hat{R}_1=5, \hat{R}_2=3, \hat{R}_3=8$. $\gamma$=0.9. Compute the synthetic return $G_0^{\text{model}}$.

💡 Show answer
$$G_0^{\text{model}} = \hat{R}_1 + \gamma \hat{R}_2 + \gamma^2 \hat{R}_3 = 5 + 0.9 \cdot 3 + 0.81 \cdot 8 = 5 + 2.7 + 6.48 = \mathbf{14.18}$$
This synthetic return is used for the REINFORCE policy gradient update.

Task 5 — When does model error hurt MBPO?

MBPO uses synthetic rollouts from the learned model. When does model error start hurting performance? How can you mitigate it?

💡 Show answer
Model error hurts when:
• The model is inaccurate (early training, rarely visited states)
• Rollout horizon H is long (errors compound: $\hat{T}^H$ vs $T^H$)
• The environment is non-stationary (model becomes stale)

Mitigation strategies:
• Short rollout horizon (H=1–5) to limit error compounding
• Mix real and synthetic data (MBPO uses both)
• Uncertainty-aware planning (only plan in high-confidence regions)
• Dyna-Q+ style exploration bonus to keep model fresh
