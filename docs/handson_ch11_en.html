❓ What is Chapter 11?

Ch11 introduces Multi-Agent Reinforcement Learning (MARL). Two dispatchers share the Warsaw ASP MDP. Each agent has its own Q-table but their actions affect each other's rewards.

Four MARL algorithms

AlgorithmKey property
IQLEach agent runs Q-Learning independently. Simplest MARL.
JALEach agent models the partner's action frequency $\hat{\pi}_j(a|s)$
Lenient QNegative TD errors ignored with probability μ
Mean Field QApproximate joint action by mean action of neighbours

🧮 IQL (Independent Q-Learning)

$$Q_i(s,a) \leftarrow Q_i(s,a) + \alpha \left[ r + \gamma \max_{a'} Q_i(s',a') - Q_i(s,a) \right]$$
Each agent treats the other as part of the environment. Simple but non-stationary: the environment changes as the other agent learns.

JAL (Joint Action Learning)

$$\hat{\pi}_j(a|s) = \frac{N_j(s,a)}{\sum_{a'} N_j(s,a')}$$
$$Q_i(s,a) \leftarrow Q_i(s,a) + \alpha \left[ r + \gamma \mathbb{E}_{\hat{\pi}_j}[\max Q_i(s')] - Q_i(s,a) \right]$$
Agent $i$ models partner $j$'s policy from action frequencies. Q update uses expected value over estimated partner policy.

Lenient Q-Learning

$$\delta = r + \gamma \max Q_i(s') - Q_i(s,a)$$
Apply update only if $\delta \geq 0$, or with probability $(1-\mu)$ if $\delta < 0$. $\mu=0$ → IQL. $\mu=1$ → never penalise. Prevents penalising good actions due to partner's mistakes.

Mean Field Q-Learning

$$\bar{a}_j(s) = \frac{1}{N} \sum_t a_j^{(t)}(s)$$
$$Q_i(s,a) \leftarrow Q_i(s,a) + \alpha \left[ r + \beta \bar{a}_j/|A| + \gamma \max Q_i(s') - Q_i(s,a) \right]$$
Approximate joint action by mean action of neighbours. Scales to large N. Foundation for large MARL.

Task 1 — IQL update

Agent 0, state S3, action A1: $Q_0(S3,A1)=8$. Joint reward r=5. Next state S5: $\max_{a'} Q_0(S5,a')=12$. α=0.1, γ=0.95. Compute new $Q_0(S3,A1)$.

💡 Show answer
$$\delta = r + \gamma \max_{a'} Q_0(S5,a') - Q_0(S3,A1) = 5 + 0.95 \cdot 12 - 8 = 5 + 11.4 - 8 = 8.4$$
$$Q_0(S3,A1) \leftarrow 8 + 0.1 \cdot 8.4 = \mathbf{8.84}$$

Task 2 — JAL partner model

Agent 1 has taken actions in state S2: A0 (3 times), A1 (5 times), A2 (2 times). Compute $\hat{\pi}_1(A1|S2)$.

💡 Show answer
$$\hat{\pi}_1(A1|S2) = \frac{N_1(S2,A1)}{\sum_{a'} N_1(S2,a')} = \frac{5}{3+5+2} = \frac{5}{10} = \mathbf{0.5}$$

Task 3 — Lenient Q update

$\delta = -2.5$ (negative TD error). μ=0.6. Should the update be applied? With what probability?

💡 Show answer
Since $\delta < 0$, Lenient Q applies the update with probability $(1-\mu) = 1 - 0.6 = \mathbf{0.4}$.

With probability 0.6, the negative update is ignored — this prevents penalising good actions due to partner's mistakes.

If $\delta \geq 0$, the update is always applied (probability 1.0).

Task 4 — Mean Field update

Agent 0, state S4, action A1: $Q_0(S4,A1)=10$. Joint reward r=4. $\bar{a}_1(S4)=1.5$ (mean partner action), $|A|=4$. $\max Q_0(S5)=15$. α=0.1, γ=0.9, β=0.5. Compute new $Q_0(S4,A1)$.

💡 Show answer
$$\delta = r + \beta \bar{a}_1/|A| + \gamma \max Q_0(S5) - Q_0(S4,A1)$$
$$= 4 + 0.5 \cdot 1.5/4 + 0.9 \cdot 15 - 10 = 4 + 0.1875 + 13.5 - 10 = 7.6875$$
$$Q_0(S4,A1) \leftarrow 10 + 0.1 \cdot 7.6875 = \mathbf{10.769}$$

Task 5 — Why IQL struggles

Explain the non-stationarity problem in IQL and why it can prevent convergence.

💡 Show answer
In IQL, each agent treats the other as part of the environment. But the other agent is also learning — its policy changes over time.

From Agent 0's perspective: the "environment" (Agent 1's behaviour) is non-stationary. Q-Learning convergence requires a stationary environment.

Consequence: Agent 0's Q-values may never converge because Agent 1 keeps changing. The agents may cycle between policies without reaching equilibrium.

Solution: JAL (model partner explicitly), Lenient Q (ignore partner mistakes), or centralised training (Ch12–Ch13).
