❓ What is Chapter 12?

Ch12 applies Game Theory to MARL. Instead of just learning Q-values, agents compute equilibrium strategies that are stable against rational opponents.

Four algorithms

AlgorithmEquilibrium concept
Nash Q-LearningNash equilibrium — neither player can improve unilaterally
Correlated Q-LearningCorrelated equilibrium — broader than Nash, via joint distribution
Minimax Q-LearningZero-sum: maximise worst-case payoff
Fictitious PlayBest response to opponent's empirical average strategy

🧮 Nash Equilibrium

$$V_i(s, \pi_i^*, \pi_j^*) \geq V_i(s, \pi_i, \pi_j^*) \quad \forall \pi_i$$
Neither player can improve their value by deviating unilaterally. The stable operating point of the game.

Nash Q-Learning

$$Q_i(s,a_0,a_1) \leftarrow Q_i + \alpha \left[ r_i + \gamma V_i^{\text{Nash}}(s') - Q_i(s,a_0,a_1) \right]$$
$V_i^{\text{Nash}}(s)$ = Nash equilibrium value. Converges to Nash equilibrium in self-play.

Correlated Q-Learning

$$\sigma(a_0,a_1|s) \text{ updated via regret matching}$$
Joint distribution $\sigma$ over action pairs. Broader than Nash — agents can coordinate via correlated signals. Updated via regret matching.

Minimax Q-Learning

$$V_0^{mm}(s) = \max_{\pi_0} \min_{\pi_1} \sum_{a_0,a_1} \pi_0(a_0) \pi_1(a_1) Q_0(s,a_0,a_1)$$
Zero-sum game: Player 0 maximises worst-case payoff. Optimal for adversarial settings.

Fictitious Play

$$\hat{\pi}_j(a|s) = \frac{N_j(s,a)}{\sum_{a'} N_j(s,a')}$$
Best response to opponent's empirical average strategy. Converges to Nash in two-player zero-sum games.

Task 1 — Nash Equilibrium definition

Player 0 has strategy $\pi_0^*$, Player 1 has $\pi_1^*$. Is this a Nash Equilibrium if Player 0 can gain +2 by switching to $\pi_0'$?

💡 Show answer
No — this is NOT a Nash Equilibrium.

Nash Equilibrium requires: $V_i(s, \pi_i^*, \pi_j^*) \geq V_i(s, \pi_i, \pi_j^*)$ for ALL $\pi_i$.

If Player 0 can gain +2 by switching to $\pi_0'$, then $V_0(s, \pi_0', \pi_1^*) > V_0(s, \pi_0^*, \pi_1^*)$, which violates the Nash condition.

Task 2 — Nash Q update

$Q_0(S3,A0,A1)=8$. Joint reward $r_0=5$. $V_0^{\text{Nash}}(S5)=12$. α=0.1, γ=0.95. Compute new $Q_0(S3,A0,A1)$.

💡 Show answer
$$\delta = r_0 + \gamma V_0^{\text{Nash}}(S5) - Q_0(S3,A0,A1) = 5 + 0.95 \cdot 12 - 8 = 5 + 11.4 - 8 = 8.4$$
$$Q_0(S3,A0,A1) \leftarrow 8 + 0.1 \cdot 8.4 = \mathbf{8.84}$$

Task 3 — Minimax value

Zero-sum game, state S2. Player 0 has two actions, Player 1 has two actions. Payoff matrix for Player 0: [[3, -1], [1, 2]]. What is the Minimax value for Player 0?

💡 Show answer
Player 0 maximises, Player 1 minimises Player 0's payoff:

If Player 0 plays A0: Player 1 minimises → min(3, -1) = -1
If Player 0 plays A1: Player 1 minimises → min(1, 2) = 1

Player 0 maximises over these: max(-1, 1) = 1

Minimax value = 1. Player 0 should play A1 (guarantees at least 1 regardless of Player 1's action).

Task 4 — Fictitious Play update

Player 1 has played in state S4: A0 (4 times), A1 (6 times). Player 0's best response to $\hat{\pi}_1$: Q(S4,A0)=8 vs Q(S4,A1)=10 (against A0), Q(S4,A0)=12 vs Q(S4,A1)=7 (against A1). What is Player 0's best response?

💡 Show answer
$\hat{\pi}_1(A0|S4) = 4/10 = 0.4$, $\hat{\pi}_1(A1|S4) = 6/10 = 0.6$

Expected value for Player 0:
$\mathbb{E}[Q(S4,A0)] = 0.4 \cdot 8 + 0.6 \cdot 12 = 3.2 + 7.2 = 10.4$
$\mathbb{E}[Q(S4,A1)] = 0.4 \cdot 10 + 0.6 \cdot 7 = 4.0 + 4.2 = 8.2$

Best response: A0 (expected value 10.4 > 8.2).

Task 5 — Nash vs Correlated equilibrium

Explain the difference between Nash Equilibrium and Correlated Equilibrium. When is Correlated Equilibrium more useful?

💡 Show answer
Nash Equilibrium: Each player's strategy is a best response to the other's strategy. Players act independently — no coordination signal needed.

Correlated Equilibrium: A joint distribution $\sigma(a_0,a_1|s)$ over action pairs. A mediator (or public signal) recommends actions. Each player's recommended action is a best response given the other follows the recommendation.

Key difference: Correlated equilibrium is broader — every Nash equilibrium is a correlated equilibrium, but not vice versa.

More useful when: Agents can observe a common signal (e.g., traffic light, shared sensor). Correlated equilibrium can achieve higher joint payoffs than Nash in coordination games.

✅ Game theory insights
  • Nash Q: converges to stable equilibrium
  • Correlated Q: broader than Nash
  • Minimax: optimal for adversarial settings
  • Fictitious Play: simple, converges in zero-sum
❌ Limitations
  • Joint Q-table: $O(|S||A|^N)$ memory
  • Nash computation is NP-hard in general
  • Multiple Nash equilibria may exist
  • Assumes rational opponents
