❓ What is Chapter 13?

Ch13 introduces Cooperative MARL with value decomposition. Agents share the same joint reward and use a mixing network to decompose $Q_{tot}$ into individual $Q_i$ values.

🧮 IGM Property

$$\arg\max_{\mathbf{a}} Q_{tot}(s,\mathbf{a}) = (\arg\max_{a_0} Q_0(s_0,a_0),\ \arg\max_{a_1} Q_1(s_1,a_1))$$
Individual-Global-Max: the joint greedy action equals the tuple of individual greedy actions. Enables decentralised execution — each agent just maximises its own $Q_i$.

VDN (Value Decomposition Networks)

$$Q_{tot} = Q_0(s_0,a_0) + Q_1(s_1,a_1)$$
$$\frac{\partial Q_{tot}}{\partial Q_i} = 1 \quad \text{(equal gradient for both agents)}$$
Simple additive decomposition. Satisfies IGM. Equal credit to both agents. Implemented in vdn().

QMIX

$$Q_{tot} = w_0(s) Q_0 + w_1(s) Q_1 + b(s), \quad w_i(s) \geq 0$$
$$\frac{\partial Q_{tot}}{\partial Q_i} = w_i(s) \quad \text{(state-dependent gradient)}$$
Monotone mixing: $w_i(s) \geq 0$ ensures IGM. State-dependent weights allow richer decomposition than VDN. Implemented in qmix().

QMIX+CG (Counterfactual Baseline)

$$A_i = Q_{tot}(s,\mathbf{a}) - Q_{tot}(s, \mathbf{a}_{-i}, \arg\max Q_i)$$
Counterfactual advantage: isolates agent $i$'s contribution to joint value. Better credit assignment — each agent knows how much it contributed. Implemented in qmix_cg().

🗺 Cooperative MARL Environment

Two agents share the same joint reward. Both agents' actions contribute to $Q_{tot}$. The mixing network is trained centrally but agents execute decentrally.

Task 1 — VDN decomposition

$Q_0(S3,A1)=8$, $Q_1(S3,A0)=6$. Compute $Q_{tot}^{VDN}(S3, A1, A0)$. What is $\partial Q_{tot}/\partial Q_0$?

💡 Show answer
$$Q_{tot}^{VDN} = Q_0(S3,A1) + Q_1(S3,A0) = 8 + 6 = \mathbf{14}$$
$$\frac{\partial Q_{tot}}{\partial Q_0} = 1 \quad \text{(equal gradient for both agents)}$$
Both agents receive equal credit for the joint value.

Task 2 — QMIX decomposition

State S3: $w_0(S3)=0.7$, $w_1(S3)=0.4$, $b(S3)=2$. $Q_0(S3,A1)=8$, $Q_1(S3,A0)=6$. Compute $Q_{tot}^{QMIX}$. What is $\partial Q_{tot}/\partial Q_0$?

💡 Show answer
$$Q_{tot}^{QMIX} = w_0(S3) Q_0 + w_1(S3) Q_1 + b(S3) = 0.7 \cdot 8 + 0.4 \cdot 6 + 2 = 5.6 + 2.4 + 2 = \mathbf{10.0}$$
$$\frac{\partial Q_{tot}}{\partial Q_0} = w_0(S3) = \mathbf{0.7}$$
Agent 0 receives more credit (0.7) than Agent 1 (0.4) in state S3.

Task 3 — IGM property verification

$Q_0(S2) = [5, 8, 3]$ (for A0, A1, A2). $Q_1(S2) = [7, 4, 9]$. QMIX weights: $w_0=0.6$, $w_1=0.4$. Verify IGM: does $\arg\max Q_{tot}$ equal $(\arg\max Q_0, \arg\max Q_1)$?

💡 Show answer
$\arg\max Q_0 = A1$ (value 8). $\arg\max Q_1 = A2$ (value 9).

$Q_{tot}(A1,A2) = 0.6 \cdot 8 + 0.4 \cdot 9 = 4.8 + 3.6 = 8.4$

Check all combinations: $Q_{tot}(A0,A2) = 0.6 \cdot 5 + 0.4 \cdot 9 = 6.6$, $Q_{tot}(A1,A0) = 0.6 \cdot 8 + 0.4 \cdot 7 = 7.6$

$\arg\max Q_{tot} = (A1, A2)$ ✅ = $(\arg\max Q_0, \arg\max Q_1)$. IGM is satisfied.

Task 4 — Counterfactual advantage

$Q_{tot}(S3, A1, A0)=12$. Counterfactual: $Q_{tot}(S3, \arg\max Q_0, A0) = Q_{tot}(S3, A1, A0) = 12$ (A1 is already greedy for Agent 0). Compute $A_1$ (Agent 1's counterfactual advantage).

💡 Show answer
$$A_1 = Q_{tot}(S3, A1, A0) - Q_{tot}(S3, A1, \arg\max Q_1)$$
If $\arg\max Q_1 = A0$ (Agent 1's greedy action is A0), then:
$$A_1 = 12 - 12 = \mathbf{0}$$
Agent 1's counterfactual advantage is 0 — it is already playing its greedy action. If Agent 1 had played a suboptimal action, $A_1$ would be negative.

Task 5 — Why QMIX outperforms VDN

Both VDN and QMIX satisfy IGM. Why does QMIX typically achieve higher joint returns than VDN?

💡 Show answer
VDN limitation: $Q_{tot} = Q_0 + Q_1$ assumes equal contribution from both agents in all states. The gradient $\partial Q_{tot}/\partial Q_i = 1$ is constant — no state-dependent credit assignment.

QMIX advantage: $Q_{tot} = w_0(s)Q_0 + w_1(s)Q_1 + b(s)$ with state-dependent weights. In some states, Agent 0 may be more important ($w_0 > w_1$); in others, Agent 1 may be more important. The mixing network learns this from data.

Result: QMIX can represent a richer class of joint value functions while still satisfying IGM (monotonicity: $w_i \geq 0$). This leads to better credit assignment and higher joint returns.
