🧮 MARL Objective

$$J_i(\pi_i) = \mathbb{E}\left[\sum_{t=0}^\infty \gamma^t r_i^t \mid \pi, P\right]$$
Each agent $i$ maximises its own discounted return. The joint policy $\pi = (\pi_1, \ldots, \pi_N)$ determines the system behaviour.

IQL Update

$$Q_i(s_i, a_i) \leftarrow Q_i(s_i, a_i) + \alpha \left[ r_i + \gamma \max_{a'} Q_i(s_i', a') - Q_i(s_i, a_i) \right]$$
Each agent treats others as part of the environment. Non-stationary: environment changes as other agents learn. Implemented in run_iql().

VDN Decomposition

$$Q_{tot}(s, \mathbf{a}) = \sum_{i=1}^N Q_i(s_i, a_i)$$
$$\frac{\partial Q_{tot}}{\partial Q_i} = 1 \quad \text{(equal credit for all agents)}$$
Joint reward shared equally. Satisfies IGM. Implemented in run_vdn().

MAPG Policy Gradient

$$\nabla_{\theta_i} J_i = \mathbb{E}\left[\nabla_{\theta_i} \log \pi_{\theta_i}(a_i \mid s_i) A_i(s_i, a_i)\right]$$
$$J_i^{\text{entropy}}(\theta_i) = J_i(\theta_i) + \beta H(\pi_{\theta_i})$$
Entropy bonus $\beta H(\pi)$ prevents premature convergence. Implemented in run_mapg().

MADDPG — Centralised Critic

$$Q_{\phi_i}(s, \mathbf{a}) \leftarrow Q_{\phi_i} + \alpha \left[ r_i + \gamma Q_{\phi_i}(s', \mathbf{a}') - Q_{\phi_i}(s, \mathbf{a}) \right]$$
$$\theta_{\text{target}} \leftarrow \tau \theta + (1-\tau) \theta_{\text{target}}$$
Centralised critic uses joint state $(s_0, s_1)$ and joint action $(a_0, a_1)$. Soft update $\tau$ stabilises training. Decentralised actors execute independently. Implemented in run_maddpg().

Advantage Function

$$A_i(s_i, a_i) = Q_i(s_i, a_i) - V_i(s_i)$$
Measures how much better action $a_i$ is compared to the average. Used in MAPG and MADDPG actor updates.

🗺 5×5 Grid World

Two agents navigate a 5×5 grid. Each cell has a resource value (0–5) that depletes when collected. Agents start at (0,0) and (4,4). Target at (2,2).

Actions

ActionDirectionEffect
0UpRow −1 (clamped)
1DownRow +1 (clamped)

Reward Function

$$R_t = R_{\text{cell}} - 0.1 \cdot d(s_t, \text{target})$$
$R_{\text{cell}}$ = resource value at new position (depleted after collection). $d$ = Euclidean distance to target (2,2). Encourages both resource collection and target proximity.

📊 Interpreting the results

📈 Episode Returns Chart

Axes: X = episode, Y = total return (MA-20)
Purpose: Shows how each algorithm improves over time.
What to watch:
• MADDPG should converge fastest (centralised critic stabilises learning)
• VDN should outperform IQL (shared reward signal)
• MAPG may be noisy early (high variance policy gradient)

🤝 Cooperation Rate Chart

Purpose: Fraction of steps where both agents chose the same action.
What to watch:
• MADDPG should have highest cooperation (centralised critic coordinates)
• IQL may have low cooperation (non-stationary environment)
• VDN improves over IQL due to shared reward

📉 TD Error Chart

Purpose: Shows how prediction errors decay over training.
What to watch:
• Should decrease toward zero as Q-values converge
• MADDPG TD error may be higher early (joint state space is larger)
• MAPG shows policy gradient magnitude instead of TD error

🗺 Q-Table Heatmaps

Purpose: Shows learned Q-values (IQL/VDN) or policy logits (MAPG/MADDPG) for Agent 0.
Axes: Y = state (row,col), X = action (Up/Down/Left/Right)
What to watch:
• Bright cells = preferred actions in that state
• States near target (2,2) should prefer actions that move toward it
• MADDPG logits should be sharpest (most deterministic policy)

Task 1 — IQL update

Agent 0 at state (1,2), takes action Up (0), gets reward R=3, moves to (0,2). Q(1,2,Up)=5. $\max_{a'} Q(0,2,a')=8$. α=0.1, γ=0.95. Compute new Q(1,2,Up).

💡 Show answer
$$\delta = R + \gamma \max_{a'} Q(0,2,a') - Q(1,2,\text{Up}) = 3 + 0.95 \cdot 8 - 5 = 3 + 7.6 - 5 = 5.6$$
$$Q(1,2,\text{Up}) \leftarrow 5 + 0.1 \cdot 5.6 = \mathbf{5.56}$$

Task 2 — VDN joint reward

Agent 0 gets reward 4, Agent 1 gets reward 2. Compute the VDN joint reward each agent uses for its Q update.

💡 Show answer
$$R_{\text{VDN}} = \frac{R_0 + R_1}{N} = \frac{4 + 2}{2} = \mathbf{3.0}$$
Both agents use R=3.0 for their Q updates. This is the additive decomposition: $Q_{tot} = Q_0 + Q_1$, so each agent gets equal credit.

Task 3 — MAPG softmax policy

Agent 0 at state (2,2), logits: $\theta = [1.0, 2.0, 0.5, 1.5]$. Compute $\pi(a=1|\text{Down})$.

💡 Show answer
$$\pi(\text{Down}) = \frac{e^{2.0}}{e^{1.0} + e^{2.0} + e^{0.5} + e^{1.5}} = \frac{7.389}{2.718 + 7.389 + 1.649 + 4.482} = \frac{7.389}{16.238} \approx \mathbf{0.455}$$

Task 4 — MADDPG soft update

Critic weight $\theta=0.8$, target weight $\theta_{\text{target}}=0.5$, τ=0.01. Compute new $\theta_{\text{target}}$.

💡 Show answer
$$\theta_{\text{target}} \leftarrow \tau \theta + (1-\tau)\theta_{\text{target}} = 0.01 \cdot 0.8 + 0.99 \cdot 0.5 = 0.008 + 0.495 = \mathbf{0.503}$$
The target network moves slowly toward the main network. This stabilises training by preventing oscillations.

Task 5 — Why MADDPG outperforms IQL

Both IQL and MADDPG use Q-Learning. Why does MADDPG typically achieve higher returns and cooperation?

💡 Show answer
IQL limitation: Each agent treats the other as part of the environment. Non-stationarity: as Agent 1 learns, Agent 0's environment changes → Q-values may not converge.

MADDPG advantages:
• Centralised critic $Q(s_0, s_1, a_0, a_1)$ uses joint information → stable training
• Soft target update $\tau$ prevents oscillations
• Decentralised actors still execute independently → scalable
• CTDE paradigm: train with global info, execute with local info
