🧮 Deep Neural Network

$$f_\theta(x) = f_L \circ f_{L-1} \circ \cdots \circ f_1(x)$$
Each layer: $f_i(x) = \sigma(W_i x + b_i)$. Parameters $\theta = \{W_i, b_i\}$ learned by gradient descent.

Universal Approximation Theorem (UAT)

$$\sup_{x \in K} |f(x) - \phi(x)| < \varepsilon$$
For any continuous $f$ on compact $K \subseteq \mathbb{R}^n$ and any $\varepsilon > 0$, there exists a FNN $\phi$ that approximates $f$ to within $\varepsilon$. This justifies using FNNs to approximate $V^*(s)$ and $Q^*(s,a)$.

Backpropagation

$$\frac{\partial L}{\partial \theta_i} = \frac{\partial L}{\partial f_i} \cdot \frac{\partial f_i}{\partial \theta_i}$$
$$\theta_{t+1} = \theta_t - \alpha \nabla_\theta L$$
Chain rule applied layer by layer. Implemented in backward() in ch15_deep_learning.rs.

Activation Functions

FunctionFormulaKey property
ReLU$\max(0, x)$Simple, fast, dead neuron problem
LeakyReLU$x$ if $x>0$ else $0.01x$Fixes dead neurons
ELU$x$ if $x\geq0$ else $\alpha(e^x-1)$Smooth, mean-zero activations
Swish$x \cdot \sigma(x)$Smooth, outperforms ReLU in deep nets
Tanh$\frac{e^x - e^{-x}}{e^x + e^{-x}}$Zero-centred, vanishing gradient
Sigmoid$\frac{1}{1+e^{-x}}$Output in (0,1), vanishing gradient

Adam Optimizer

$$\theta_t = \theta_{t-1} - \frac{\eta}{\sqrt{\hat{v}_t} + \epsilon} \hat{m}_t$$
$\hat{m}_t$ = bias-corrected first moment (momentum). $\hat{v}_t$ = bias-corrected second moment (adaptive LR). Combines momentum + RMSProp. Implemented in backward() with optimizer="adam".

L2 Regularization

$$L(\theta) = L_{\text{data}} + \lambda \|\theta\|^2$$
Penalises large weights. Gradient: $\nabla_\theta L = \nabla_\theta L_{\text{data}} + 2\lambda\theta$. Prevents overfitting to training states.

Dropout

$$a_i^{\text{dropout}} = \begin{cases} a_i / (1-p) & \text{with probability } 1-p \\ 0 & \text{with probability } p \end{cases}$$
Randomly zeros neurons during training. Inverted dropout: scale by $1/(1-p)$ to keep expected value. Implemented in forward() with training=true.

Task 1 — Forward pass

FNN with 1 hidden layer (2 neurons, ReLU). Input $x=[1.0, 0.5]$. Weights: $W_1=[[0.5, -0.3],[0.2, 0.8]]$, $b_1=[0.1, -0.1]$. Output layer: $W_2=[[0.6, 0.4]]$, $b_2=[0.0]$. Compute the output.

💡 Show answer
Hidden layer pre-activation:
$$z_1 = W_1 x + b_1 = \begin{bmatrix}0.5(1.0) + (-0.3)(0.5) + 0.1 \\ 0.2(1.0) + 0.8(0.5) + (-0.1)\end{bmatrix} = \begin{bmatrix}0.45 \\ 0.50\end{bmatrix}$$
After ReLU: $a_1 = [0.45, 0.50]$ (both positive, unchanged)
Output:
$$\hat{y} = W_2 a_1 + b_2 = 0.6(0.45) + 0.4(0.50) + 0 = 0.27 + 0.20 = \mathbf{0.47}$$

Task 2 — MSE loss and gradient

FNN output $\hat{y}=0.47$, true target $y=0.80$. Compute MSE loss and the output gradient $\partial L / \partial \hat{y}$.

💡 Show answer
$$L = \frac{1}{1}(\hat{y} - y)^2 = (0.47 - 0.80)^2 = (-0.33)^2 = \mathbf{0.1089}$$
$$\frac{\partial L}{\partial \hat{y}} = 2(\hat{y} - y) = 2(0.47 - 0.80) = \mathbf{-0.66}$$
Negative gradient: the output needs to increase to reduce the loss.

Task 3 — Adam update

Parameter $\theta=0.5$, gradient $g=0.2$. Adam state: $m=0.0$, $v=0.0$, $t=1$. $\eta=0.01$, $\beta_1=0.9$, $\beta_2=0.999$, $\epsilon=10^{-8}$. Compute new $\theta$.

💡 Show answer
$$m_1 = 0.9 \cdot 0 + 0.1 \cdot 0.2 = 0.02$$
$$v_1 = 0.999 \cdot 0 + 0.001 \cdot 0.04 = 0.00004$$
$$\hat{m}_1 = \frac{0.02}{1 - 0.9} = 0.2, \quad \hat{v}_1 = \frac{0.00004}{1 - 0.999} = 0.04$$
$$\theta_1 = 0.5 - \frac{0.01}{\sqrt{0.04} + 10^{-8}} \cdot 0.2 = 0.5 - \frac{0.01}{0.2} \cdot 0.2 = 0.5 - 0.01 = \mathbf{0.49}$$

Task 4 — L2 regularization gradient

Weight $w=0.8$, data gradient $\partial L_{\text{data}}/\partial w = 0.3$, $\lambda=0.01$. Compute the regularised gradient and new weight after one SGD step with $\alpha=0.1$.

💡 Show answer
$$\frac{\partial L}{\partial w} = \frac{\partial L_{\text{data}}}{\partial w} + 2\lambda w = 0.3 + 2(0.01)(0.8) = 0.3 + 0.016 = \mathbf{0.316}$$
$$w_{\text{new}} = 0.8 - 0.1 \cdot 0.316 = 0.8 - 0.0316 = \mathbf{0.7684}$$
L2 regularization pulls the weight toward zero (weight decay).

Task 5 — Why FNN for V*(s)?

Ch02 computes V*(s) exactly using Value Iteration. Why would we use a FNN to approximate V*(s) instead?

💡 Show answer
Value Iteration (Ch02) limitations:
• Requires full model $P(s'|s,a)$ — not available in real dispatch
• Tabular: $O(|S|)$ memory — infeasible for large/continuous state spaces
• Cannot generalise: V(S3) tells us nothing about a new state S3'

FNN advantages:
• Generalises: learns $V^*(s)$ as a function of features, not a lookup table
• Scales to continuous state spaces (GPS coordinates, real-time SLA rates)
• Foundation for DQN (Ch16): $Q(s,a;\theta)$ approximated by FNN
• Can be trained from experience without knowing $P(s'|s,a)$
