🧮 DQN — Bellman + FNN

$$Q(s,a;\theta) \approx r + \gamma \max_{a'} Q(s',a';\theta^-)$$
$\theta$ = main network weights. $\theta^-$ = target network weights (frozen, updated every $C$ steps). Experience replay: sample $(s,a,r,s')$ from buffer $\mathcal{D}$.

DQN Loss

$$L(\theta) = \mathbb{E}_{(s,a,r,s') \sim \mathcal{D}} \left[ \left( y - Q(s,a;\theta) \right)^2 \right]$$
$$y = r + \gamma \max_{a'} Q(s',a';\theta^-)$$
MSE between predicted Q-value and TD target $y$. Target uses frozen $\theta^-$ to stabilise training. Implemented in run_dqn().

Double DQN — Fix Overestimation

$$y = r + \gamma Q\!\left(s',\, \arg\max_{a'} Q(s',a';\theta);\, \theta^-\right)$$
Main network $\theta$ selects the action. Target network $\theta^-$ evaluates it. Decoupling prevents overestimation. Implemented in run_double_dqn().

Dueling DQN — V(s) + A(s,a)

$$Q(s,a) = V(s) + A(s,a) - \frac{1}{|\mathcal{A}|}\sum_{a'} A(s,a')$$
$V(s)$ = value of being in state $s$ (independent of action). $A(s,a)$ = advantage of action $a$ over average. Subtracting mean advantage ensures identifiability. Implemented in run_dueling_dqn().

PPO — Clipped Surrogate

$$r_\theta(s,a) = \frac{\pi_\theta(a|s)}{\pi_{\theta_{\text{old}}}(a|s)}$$
$$L^{\text{CLIP}}(\theta) = \mathbb{E}\left[\min\left(r_\theta A,\; \text{clip}(r_\theta, 1-\epsilon, 1+\epsilon) A\right)\right]$$
Clipping prevents large policy updates. $\epsilon=0.2$ is standard. Combined loss: $L = L^{\text{CLIP}} - c_1 L^{\text{value}} + c_2 H(\pi)$. Implemented in run_ppo().

Experience Replay

$$(s,a,r,s') \sim \mathcal{D} \quad \text{uniformly}$$
Breaks temporal correlations. Allows reuse of past transitions. Buffer size = 1000–5000 for this environment. Implemented in ReplayBuffer struct.

📊 Interpreting the results

📈 Episode Returns Chart

Axes: X = episode, Y = total return (MA-20)
Purpose: Shows how each algorithm improves over time.
What to watch:
• All algorithms should improve over episodes
• Dueling DQN often converges fastest (separate V/A streams)
• PPO may be noisier early (policy gradient variance)
• Double DQN should outperform DQN (less overestimation)

📉 Loss Chart (log scale)

Purpose: Shows TD error decay for DQN variants.
What to watch:
• Should decrease toward zero as Q-values converge
• Spikes = target network update (expected)
• PPO loss is excluded (different scale — policy gradient loss)

📉 Epsilon Decay Chart

Purpose: Shows exploration rate over training.
• Starts at ε=1.0 (fully random)
• Decays exponentially to ε=0.05 (mostly greedy)
• PPO has no ε (uses stochastic policy for exploration)

🗺 Q-Table Heatmaps

Purpose: Shows learned Q-values for each (state, action) pair.
Axes: Y = state (S0–S7), X = action
What to watch:
• S0 should have highest Q-values (best dispatch state)
• S7 should have lowest Q-values (worst state)
• Dispatch+1 from S0 should be highest Q-value overall
• PPO shows policy logits (not Q-values) — higher = more likely action

Task 1 — DQN TD target

Agent at S2, takes Dispatch+1, gets reward R=1.5, moves to S3. Target network: $\max_{a'} Q(S3,a';\theta^-)=8.0$. $\gamma=0.95$. Compute the TD target $y$.

💡 Show answer
$$y = R + \gamma \max_{a'} Q(S3,a';\theta^-) = 1.5 + 0.95 \times 8.0 = 1.5 + 7.6 = \mathbf{9.1}$$

Task 2 — Double DQN target

At S3, main network selects $a^* = \arg\max_{a'} Q(S3,a';\theta) = \text{Dispatch+1}$. Target network: $Q(S3, \text{Dispatch+1};\theta^-)=7.5$. R=1.2, $\gamma=0.95$. Compute Double DQN target.

💡 Show answer
$$y = R + \gamma Q(S3, a^*;\theta^-) = 1.2 + 0.95 \times 7.5 = 1.2 + 7.125 = \mathbf{8.325}$$
Double DQN uses the main network to SELECT the action but the TARGET network to EVALUATE it. This prevents overestimation.

Task 3 — Dueling DQN decomposition

At S1: $V(S1)=12.0$. Advantage stream outputs: $A(S1,a_0)=2.0$, $A(S1,a_1)=1.0$, $A(S1,a_2)=-0.5$, $A(S1,a_3)=-2.5$. Compute $Q(S1,a_0)$.

💡 Show answer
$$\bar{A} = \frac{2.0 + 1.0 + (-0.5) + (-2.5)}{4} = \frac{0.0}{4} = 0.0$$
$$Q(S1, a_0) = V(S1) + A(S1,a_0) - \bar{A} = 12.0 + 2.0 - 0.0 = \mathbf{14.0}$$

Task 4 — PPO clipping

Old policy: $\pi_{\theta_{\text{old}}}(a|s)=0.4$. New policy: $\pi_\theta(a|s)=0.6$. Advantage $A=2.0$. $\epsilon=0.2$. Compute $L^{\text{CLIP}}$ for this sample.

💡 Show answer
$$r_\theta = \frac{0.6}{0.4} = 1.5$$
$$\text{clip}(1.5, 0.8, 1.2) = 1.2$$
$$L^{\text{CLIP}} = \min(1.5 \times 2.0,\; 1.2 \times 2.0) = \min(3.0, 2.4) = \mathbf{2.4}$$
The clipping prevents the policy from updating too aggressively when $r_\theta > 1+\epsilon$.

Task 5 — Why experience replay?

Without experience replay, DQN trains on consecutive transitions $(s_t, a_t, r_t, s_{t+1})$. Why is this problematic and how does replay fix it?

💡 Show answer
Problem without replay:
• Consecutive transitions are highly correlated (same trajectory)
• Network overfits to recent experience
• Catastrophic forgetting: learning S5 may overwrite S0 knowledge
• Non-i.i.d. samples violate SGD assumptions → divergence

How replay fixes it:
• Stores $(s,a,r,s')$ in buffer $\mathcal{D}$
• Samples random mini-batches → breaks correlations
• Reuses past transitions → better sample efficiency
• Diverse samples → stable gradient estimates
