🔄 From Single-Agent to Multi-Agent RL

In Ch01–Ch16, one central dispatcher made all decisions. The environment was stationary from the agent's perspective.

In Ch17, each of the 5 technicians is an independent agent. The environment is now non-stationary from each agent's perspective — because other agents are also learning and changing their behaviour simultaneously.
Single-Agent RL (Ch01–Ch16)
• 1 agent, 1 Q-table
• Stationary environment
• Centralised decision making
• $\pi: S \to A$
Multi-Agent RL (Ch17)
• $n$ agents, $n$ Q-tables
• Non-stationary environment
• Decentralised decision making
• $\pi^i: S \to A^i$ for each agent $i$

🧮 Stochastic Game Formalism

A MARL problem is formalised as a Stochastic Game (also called Markov Game): $$\mathcal{G} = (S,\; \mathbf{A},\; P,\; \mathbf{R},\; \gamma)$$
ComponentSymbolWarsaw ASP meaning
State space$S$All technician positions + order status
Joint action space$\mathbf{A} = A^1 \times \cdots \times A^n$All technicians simultaneously choose an order
Transition$P(s'|s, \mathbf{a})$Next state depends on ALL agents' actions
Reward vector$\mathbf{R} = (R^1, \ldots, R^n)$Each agent gets its own reward (V1) or shared reward (V2)
Discount$\gamma \in [0,1]$Same as single-agent (default 0.95)

🗺 Warsaw ASP as a MARL Environment

5 agents: $T_0, T_1, T_2, T_3, T_4$ — each technician is an independent RL agent.
10 work orders: $W_0, \ldots, W_9$ — each dispatched exactly once per episode.
3 skills: HVAC, Electrical, Network — fixed per environment (seed=42).
Fixed environment: same positions every episode — only policy randomness varies.

Each agent maintains its own Q-table $Q^i[order]$ and updates it independently after each dispatch.

📋 Key MARL Challenges

⚠️ Non-stationarity
From agent $i$'s perspective, other agents are part of the environment. As they learn, the environment changes — violating the Markov assumption that single-agent RL relies on.
⚠️ Credit Assignment
With shared reward, how does agent $i$ know if its action was good or bad? The team reward mixes contributions from all agents — making it hard to assign credit correctly.
🔄 Coordination
Agents may need to coordinate (e.g. avoid sending two technicians to the same area) but without communication this is hard. V1–V2 have no coordination mechanism.
📈 Scalability
With $n$ agents, the joint action space grows as $|A|^n$. IQL avoids this by treating each agent independently, but loses global optimality guarantees.

🤖 V1 — IQL / Individual Reward / No Communication

One sentence: Each technician is a fully independent agent that learns only from its own dispatches, with no knowledge of other agents — the simplest possible MARL baseline.

🧮 IQL Theory

Independent Q-Learning (IQL) applies standard Q-Learning independently to each agent, treating other agents as part of the (non-stationary) environment.

Each agent $i$ maintains its own Q-table $Q^i$ and updates it using only its own experience:
$$Q^i(o) \leftarrow Q^i(o) + \alpha \left[ R^i + \gamma \max_{o'} Q^i(o') - Q^i(o) \right]$$
where:
$Q^i(o)$ = agent $i$'s value estimate for serving order $o$
$R^i$ = individual reward received by agent $i$ for this dispatch
$\alpha$ = learning rate · $\gamma$ = discount factor
$\max_{o'} Q^i(o')$ = best Q-value for remaining orders (from agent $i$'s perspective)

📊 What to observe in V1

Expected behaviour:
• Each agent learns independently — high variance between agents
• Agents with matching skills learn faster (higher rewards reinforce good Q-values)
• No coordination — two agents may "compete" for the same order type
• Learning curve: upward trend as $\varepsilon$ decays and agents exploit learned Q-values
• TD Error: converges toward 0 as Q-values stabilise

📝 Tasks

Task 1 — IQL update

Agent $T_2$ has $Q^2(W_5) = 0.8$. It dispatches to $W_5$, receives $R^2 = 1.5$. Next best Q-value: $\max Q^2 = 1.2$. $\alpha=0.1$, $\gamma=0.95$. Compute new $Q^2(W_5)$.

💡 Show answer
$$\delta = R^2 + \gamma \max Q^2 - Q^2(W_5) = 1.5 + 0.95 \times 1.2 - 0.8 = 1.5 + 1.14 - 0.8 = 1.84$$
$$Q^2(W_5) \leftarrow 0.8 + 0.1 \times 1.84 = \mathbf{0.984}$$

Task 2 — Why is IQL non-stationary?

Explain why the environment is non-stationary from agent $T_0$'s perspective in IQL.

💡 Show answer
From $T_0$'s perspective, the other agents $T_1, \ldots, T_4$ are part of the environment. As they learn and update their Q-tables, their policies change — which means the distribution of states $T_0$ encounters also changes over time. This violates the stationarity assumption of standard Q-Learning, which assumes $P(s'|s,a)$ is fixed.

🤝 V2 — IQL / Shared Reward / No Communication

One sentence: Identical to V1 except every agent receives the same shared reward (team mean) instead of its own individual reward — encouraging implicit cooperation without any communication.

🔄 What changes from V1 to V2

V1 — Individual Reward

Agent $T_i$ receives $R^i$ = its own dispatch reward.

$$Q^i(o) \leftarrow Q^i(o) + \alpha \left[ R^i + \gamma \max Q^i - Q^i(o) \right]$$
A lazy agent that serves far-away orders gets penalised directly.
V2 — Shared Reward

All agents receive $\bar{R}$ = mean team reward.

$$Q^i(o) \leftarrow Q^i(o) + \alpha \left[ \bar{R} + \gamma \max Q^i - Q^i(o) \right]$$
A lazy agent is penalised only if the whole team performs poorly.
$$\bar{R} = \frac{1}{n} \sum_{i=1}^{n} R^i$$

⚠️ The Credit Assignment Problem

Credit Assignment Problem: When all agents receive the same shared reward $\bar{R}$, how does agent $T_2$ know whether its own action was good or bad?

Example: $T_2$ serves a nearby skill-matched order (good action, $R^2 = +1.8$), but $T_4$ serves a far mismatched order (bad action, $R^4 = -1.2$). The shared reward is $\bar{R} = \frac{1.8 + (-1.2)}{2} = +0.3$.

$T_2$ receives only $+0.3$ instead of $+1.8$ — its good action is under-credited.
$T_4$ receives $+0.3$ instead of $-1.2$ — its bad action is over-credited.

This is the fundamental challenge of shared-reward MARL. V4–V6 address it with more sophisticated methods.

📊 What to observe in V2

Expected behaviour vs V1:
• Smoother learning curve — shared reward reduces variance between agents
• Slower individual learning — credit assignment problem dilutes the signal
• More uniform Q-tables — agents converge to similar values (same reward signal)
• Implicit cooperation — agents are incentivised to improve team performance
• TD Error — may converge slower than V1 due to noisy shared signal

📝 Tasks

Task 1 — Shared reward calculation

Episode with 5 agents. Individual rewards: $R^0=+1.8,\; R^1=-0.5,\; R^2=+1.2,\; R^3=-1.0,\; R^4=+0.8$. Compute $\bar{R}$.

💡 Show answer
$$\bar{R} = \frac{1.8 + (-0.5) + 1.2 + (-1.0) + 0.8}{5} = \frac{2.3}{5} = \mathbf{0.46}$$
Note: $T_0$ would have received $+1.8$ in V1 but only $+0.46$ in V2 — under-credited by $1.34$.

Task 2 — Credit assignment problem

$T_3$ serves a far mismatched order: $R^3 = -1.4$. Team mean: $\bar{R} = +0.6$. $Q^3(W_7)=0.2$, $\max Q^3=0.8$, $\alpha=0.1$, $\gamma=0.95$. Compute new $Q^3(W_7)$ in V2. Would it be different in V1?

💡 Show answer
V2 (shared reward $\bar{R}=+0.6$):
$$\delta = 0.6 + 0.95 \times 0.8 - 0.2 = 0.6 + 0.76 - 0.2 = 1.16$$
$$Q^3(W_7) \leftarrow 0.2 + 0.1 \times 1.16 = \mathbf{0.316}$$
V1 (individual reward $R^3=-1.4$):
$$\delta = -1.4 + 0.95 \times 0.8 - 0.2 = -1.4 + 0.76 - 0.2 = -0.84$$
$$Q^3(W_7) \leftarrow 0.2 + 0.1 \times (-0.84) = \mathbf{0.116}$$
In V1, $Q^3(W_7)$ decreases (bad action penalised). In V2, it increases (bad action over-credited by team performance). This is the credit assignment problem.
