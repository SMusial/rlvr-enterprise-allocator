🧮 Gradient Feature Importance

$$\text{FI}(x_j) = \frac{1}{N} \sum_{i=1}^N \left|\frac{\partial L}{\partial x_j^{(i)}}\right|$$
Backpropagate the loss w.r.t. inputs. Large gradient = feature strongly influences the loss. Implemented in gradient_feature_importance().

Saliency Map

$$S_c(x) = \left|\frac{\partial f_c(x)}{\partial x}\right|$$
Backpropagate the output (not loss) w.r.t. inputs. Shows which input dimensions the model is most sensitive to. Implemented in saliency_map().

LIME — Local Interpretable Model-agnostic Explanations

$$\xi(x) = \arg\min_{g \in G} \mathcal{L}(f, g, \pi_x) + \Omega(g)$$
$$\mathcal{L}(f,g,\pi_x) = \sum_{z \in \mathcal{Z}} \pi_x(z)(f(z) - g(z))^2$$
$\pi_x(z) = \exp(-d(x,z)^2/\sigma^2)$ — kernel weight. $g$ = linear surrogate. Fit weighted linear regression on perturbed samples. Implemented in lime_explain().

SHAP — Shapley Values

$$\phi_i = \sum_{S \subseteq N \setminus \{i\}} \frac{|S|!(|N|-|S|-1)!}{|N|!} \left[f(S \cup \{i\}) - f(S)\right]$$
$\phi_i$ = fair contribution of feature $i$. Satisfies: efficiency ($\sum \phi_i = f(x) - f(\text{baseline})$), symmetry, dummy, linearity. Implemented via KernelSHAP in shap_values().

SHAP Efficiency Property

$$\sum_{i=1}^n \phi_i = f(x) - \mathbb{E}[f(x)]$$
The sum of all SHAP values equals the difference between the prediction and the baseline (mean prediction). This makes the waterfall chart interpretable.

📊 Interpreting the results

📊 Global Feature Importance

Purpose: Which features drive V*(s) predictions across all states?
What to watch:
• SLA Rate and Skill Match should be most important (directly drive SLA outcomes)
• Distance should be negative (higher distance = lower V*(s))
• Urgency should be positive (urgent orders need fast dispatch)

🌡 SHAP Waterfall

Purpose: Explains a single prediction as sum of feature contributions.
Reading:
• Base value = mean prediction across all states
• Green bar = feature pushes prediction UP
• Red bar = feature pushes prediction DOWN
• Final value = base + sum of all SHAP values
• For S0: SLA Rate (0.95) and Skill Match (1.0) should have large positive SHAP values

📉 LIME Chart

Purpose: Local linear approximation around the prediction.
Reading:
• Positive coefficient = feature increases V*(s) locally
• Negative coefficient = feature decreases V*(s) locally
• R² = how well the linear model fits locally (higher = more reliable)
• LIME and SHAP should agree on the sign of each feature's contribution

🗺 Comparison Heatmap

Purpose: Compare all 4 methods across all states and features.
What to watch:
• Gradient FI and Saliency should agree (both gradient-based)
• LIME and SHAP should agree on signs
• Disagreement between methods = model is complex/nonlinear in that region

Task 1 — Gradient Feature Importance

FNN output for S0: $\hat{y}=0.95$. True target: $y=1.0$. Loss: $L=(0.95-1.0)^2=0.0025$. Gradient: $\partial L/\partial x_1 = 0.08$, $\partial L/\partial x_2 = 0.03$, $\partial L/\partial x_3 = -0.12$, $\partial L/\partial x_4 = 0.05$. Rank features by importance.

💡 Show answer
$$\text{FI}(x_j) = |\partial L / \partial x_j|$$
Ranking: $x_3$ (Distance) = 0.12 > $x_1$ (SLA Rate) = 0.08 > $x_4$ (Skill Match) = 0.05 > $x_2$ (Urgency) = 0.03

Note: Distance has the highest gradient magnitude, meaning the loss is most sensitive to changes in distance for this state.

Task 2 — SHAP efficiency

For state S3: base value = 0.45, SHAP values: SLA Rate = +0.12, Urgency = +0.08, Distance = -0.05, Skill Match = +0.10. What is the predicted value?

💡 Show answer
$$\hat{y} = \text{base} + \sum_i \phi_i = 0.45 + 0.12 + 0.08 + (-0.05) + 0.10 = \mathbf{0.70}$$
This is the SHAP efficiency property: the prediction equals the baseline plus the sum of all Shapley values.

Task 3 — LIME kernel weight

Original state S0: $x_0 = [0.95, 0.9, 0.1, 1.0]$. Perturbed sample: $z = [0.85, 0.8, 0.2, 0.9]$. Compute the LIME kernel weight with $\sigma^2 = 0.25$.

💡 Show answer
$$d^2 = (0.95-0.85)^2 + (0.9-0.8)^2 + (0.1-0.2)^2 + (1.0-0.9)^2 = 0.01+0.01+0.01+0.01 = 0.04$$
$$\pi_{x_0}(z) = \exp\left(-\frac{0.04}{0.25}\right) = \exp(-0.16) \approx \mathbf{0.852}$$
Close samples get high weight (near 1.0). Distant samples get low weight (near 0.0).

Task 4 — Shapley kernel weight

$n=4$ features, coalition size $|S|=2$. Compute the Shapley kernel weight $w(S) = \frac{(n-1)!}{|S|!(n-|S|-1)!}$.

💡 Show answer
$$w(S) = \frac{(4-1)!}{2! \cdot (4-2-1)!} = \frac{3!}{2! \cdot 1!} = \frac{6}{2} = \mathbf{3}$$
Coalitions of size 1 and n-1 get the highest weight (most informative for Shapley values). Middle-sized coalitions get lower weight.

Task 5 — Why SHAP over Gradient FI?

Both Gradient FI and SHAP explain feature importance. What are the key advantages of SHAP over Gradient FI for the Warsaw ASP dispatch system?

💡 Show answer
Gradient FI limitations:
• Only measures local sensitivity at a single point
• Does not account for feature interactions
• Can be misleading for saturated activations (gradient ≈ 0 even if feature is important)
• Not additive: cannot decompose prediction into feature contributions

SHAP advantages:
• Efficiency: $\sum \phi_i = f(x) - \mathbb{E}[f(x)]$ — full decomposition of prediction
• Consistency: if a feature contributes more in model A than B, its SHAP value is higher in A
• Interactions: accounts for feature interactions via coalition sampling
• GDPR compliance: provides human-readable "right to explanation" for dispatch decisions

✅ Method strengths
  • Gradient FI: fast, differentiable, no extra samples
  • Saliency: output-level sensitivity, visual
  • LIME: model-agnostic, human-readable linear surrogate
  • SHAP: theoretically grounded, additive, GDPR-ready
❌ Limitations
  • Gradient FI: local only, misleading for saturated neurons
  • Saliency: noisy, sensitive to input normalisation
  • LIME: R² can be low for complex models
  • SHAP: expensive ($O(2^n)$ exact), KernelSHAP approximates
