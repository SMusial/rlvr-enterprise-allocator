🔄 From Single-Agent to Multi-Agent RL

In Ch01–Ch16, one central dispatcher made all decisions. The environment was stationary from the agent's perspective.

In Ch17, each of the 5 technicians is an independent agent. The environment is now non-stationary from each agent's perspective — because other agents are also learning and changing their behaviour simultaneously.
Single-Agent RL (Ch01–Ch16)
• 1 agent, 1 Q-table
• Stationary environment
• Centralised decision making
• $\pi: S \to A$
Multi-Agent RL (Ch17)
• $n$ agents, $n$ Q-tables
• Non-stationary environment
• Decentralised decision making
• $\pi^i: S \to A^i$ for each agent $i$

🧮 Stochastic Game Formalism

A MARL problem is formalised as a Stochastic Game (also called Markov Game): $$\mathcal{G} = (S,\; \mathbf{A},\; P,\; \mathbf{R},\; \gamma)$$
ComponentSymbolWarsaw ASP meaning
State space$S$All technician positions + order status
Joint action space$\mathbf{A} = A^1 \times \cdots \times A^n$All technicians simultaneously choose an order
Transition$P(s'|s, \mathbf{a})$Next state depends on ALL agents' actions
Reward vector$\mathbf{R} = (R^1, \ldots, R^n)$Each agent gets its own reward (V1) or shared reward (V2)
Discount$\gamma \in [0,1]$Same as single-agent (default 0.95)

📋 Key MARL Challenges

⚠️ Non-stationarity
From agent $i$'s perspective, other agents are part of the environment. As they learn, the environment changes — violating the Markov assumption that single-agent RL relies on.
⚠️ Credit Assignment
With shared reward, how does agent $i$ know if its action was good or bad? The team reward mixes contributions from all agents — making it hard to assign credit correctly.
🔄 Coordination
Agents may need to coordinate (e.g. avoid sending two technicians to the same area) but without communication this is hard. V1–V2 have no coordination mechanism.
📈 Scalability
With $n$ agents, the joint action space grows as $|A|^n$. IQL avoids this by treating each agent independently, but loses global optimality guarantees.

🤖 V1 — IQL / Individual Reward / No Communication

One sentence: Each technician is a fully independent agent that learns only from its own dispatches, with no knowledge of other agents — the simplest possible MARL baseline.

🧮 IQL Theory

Independent Q-Learning (IQL) applies standard Q-Learning independently to each agent, treating other agents as part of the (non-stationary) environment.

Each agent $i$ maintains its own Q-table $Q^i$ and updates it using only its own experience:
$$Q^i(o) \leftarrow Q^i(o) + \alpha \left[ R^i + \gamma \max_{o'} Q^i(o') - Q^i(o) \right]$$
where:
$Q^i(o)$ = agent $i$'s value estimate for serving order $o$
$R^i$ = individual reward received by agent $i$ for this dispatch
$\alpha$ = learning rate · $\gamma$ = discount factor
$\max_{o'} Q^i(o')$ = best Q-value for remaining orders (from agent $i$'s perspective)

📊 What to observe in V1

Expected behaviour:
• Each agent learns independently — high variance between agents
• Agents with matching skills learn faster (higher rewards reinforce good Q-values)
• No coordination — two agents may "compete" for the same order type
• Learning curve: upward trend as $\varepsilon$ decays and agents exploit learned Q-values
• TD Error: converges toward 0 as Q-values stabilise

📝 Tasks

Task 1 — IQL update

Agent $T_2$ has $Q^2(W_5) = 0.8$. It dispatches to $W_5$, receives $R^2 = 1.5$. Next best Q-value: $\max Q^2 = 1.2$. $\alpha=0.1$, $\gamma=0.95$. Compute new $Q^2(W_5)$.

💡 Show answer
$$\delta = R^2 + \gamma \max Q^2 - Q^2(W_5) = 1.5 + 0.95 \times 1.2 - 0.8 = 1.5 + 1.14 - 0.8 = 1.84$$
$$Q^2(W_5) \leftarrow 0.8 + 0.1 \times 1.84 = \mathbf{0.984}$$

Task 2 — Why is IQL non-stationary?

Explain why the environment is non-stationary from agent $T_0$'s perspective in IQL.

💡 Show answer
From $T_0$'s perspective, the other agents $T_1, \ldots, T_4$ are part of the environment. As they learn and update their Q-tables, their policies change — which means the distribution of states $T_0$ encounters also changes over time. This violates the stationarity assumption of standard Q-Learning, which assumes $P(s'|s,a)$ is fixed.

🤝 V2 — IQL / Shared Reward / No Communication

One sentence: Identical to V1 except every agent receives the same shared reward (team mean) instead of its own individual reward — encouraging implicit cooperation without any communication.

🔄 What changes from V1 to V2

V1 — Individual Reward

Agent $T_i$ receives $R^i$ = its own dispatch reward.

$$Q^i(o) \leftarrow Q^i(o) + \alpha \left[ R^i + \gamma \max Q^i - Q^i(o) \right]$$
A lazy agent that serves far-away orders gets penalised directly.
V2 — Shared Reward

All agents receive $\bar{R}$ = mean team reward.

$$Q^i(o) \leftarrow Q^i(o) + \alpha \left[ \bar{R} + \gamma \max Q^i - Q^i(o) \right]$$
A lazy agent is penalised only if the whole team performs poorly.
$$\bar{R} = \frac{1}{n} \sum_{i=1}^{n} R^i$$

⚠️ The Credit Assignment Problem

Credit Assignment Problem: When all agents receive the same shared reward $\bar{R}$, how does agent $T_2$ know whether its own action was good or bad?

Example: $T_2$ serves a nearby skill-matched order (good action, $R^2 = +1.8$), but $T_4$ serves a far mismatched order (bad action, $R^4 = -1.2$). The shared reward is $\bar{R} = \frac{1.8 + (-1.2)}{2} = +0.3$.

$T_2$ receives only $+0.3$ instead of $+1.8$ — its good action is under-credited.
$T_4$ receives $+0.3$ instead of $-1.2$ — its bad action is over-credited.

This is the fundamental challenge of shared-reward MARL. V4–V6 address it with more sophisticated methods.

📊 What to observe in V2

Expected behaviour vs V1:
• Smoother learning curve — shared reward reduces variance between agents
• Slower individual learning — credit assignment problem dilutes the signal
• More uniform Q-tables — agents converge to similar values (same reward signal)
• Implicit cooperation — agents are incentivised to improve team performance
• TD Error — may converge slower than V1 due to noisy shared signal

📝 Tasks

Task 1 — Shared reward calculation

Episode with 5 agents. Individual rewards: $R^0=+1.8,\; R^1=-0.5,\; R^2=+1.2,\; R^3=-1.0,\; R^4=+0.8$. Compute $\bar{R}$.

💡 Show answer
$$\bar{R} = \frac{1.8 + (-0.5) + 1.2 + (-1.0) + 0.8}{5} = \frac{2.3}{5} = \mathbf{0.46}$$
Note: $T_0$ would have received $+1.8$ in V1 but only $+0.46$ in V2 — under-credited by $1.34$.

Task 2 — Credit assignment problem

$T_3$ serves a far mismatched order: $R^3 = -1.4$. Team mean: $\bar{R} = +0.6$. $Q^3(W_7)=0.2$, $\max Q^3=0.8$, $\alpha=0.1$, $\gamma=0.95$. Compute new $Q^3(W_7)$ in V2. Would it be different in V1?

💡 Show answer
V2 (shared reward $\bar{R}=+0.6$):
$$\delta = 0.6 + 0.95 \times 0.8 - 0.2 = 0.6 + 0.76 - 0.2 = 1.16$$
$$Q^3(W_7) \leftarrow 0.2 + 0.1 \times 1.16 = \mathbf{0.316}$$
V1 (individual reward $R^3=-1.4$):
$$\delta = -1.4 + 0.95 \times 0.8 - 0.2 = -1.4 + 0.76 - 0.2 = -0.84$$
$$Q^3(W_7) \leftarrow 0.2 + 0.1 \times (-0.84) = \mathbf{0.116}$$
In V1, $Q^3(W_7)$ decreases (bad action penalised). In V2, it increases (bad action over-credited by team performance). This is the credit assignment problem.

👁 V3 — IQL / Individual Reward / Partial Observability

One sentence: Identical to V1 except each agent can see the positions of all other technicians and uses this information to avoid dispatching to orders already covered by a nearby colleague — distance-aware selection without any explicit communication.

🔄 What changes from V1 to V3

V1 — No Observability

Agent selects order purely by Q-value:

$$\text{score}(t, o) = Q^t(o)$$
Agent is blind to where colleagues are.
V3 — Partial Observability

Agent scores orders using Q-value + colleague distance:

$$\text{score}(t, o) = Q^t(o) + \lambda \cdot d_{\min}^{-t}(o)$$
Agent avoids orders near colleagues.

🧮 Distance-Aware Selection Formula

$$\text{score}(t,\, o) = Q^t(o) + \lambda \cdot \min_{j \neq t} d(T_j,\, W_o)$$
where:
$Q^t(o)$ = agent $t$'s Q-value for order $o$ (learned)
$\lambda$ = collision avoidance weight (UI slider, default 0.1)
$\min_{j \neq t} d(T_j, W_o)$ = distance from the nearest other technician to order $o$

Intuition:
• If a colleague is far from order $o$ → $d_{\min}$ is large → score is boosted → agent takes this order
• If a colleague is close to order $o$ → $d_{\min}$ is small → score is low → agent avoids this order

This only applies during exploitation (not exploration). During exploration, V3 behaves identically to V1.

📊 What to observe in V3

Expected behaviour vs V1:
• Lower average dispatch distance — agents avoid orders near colleagues, reducing travel overlap
• Higher SLA rate — better spatial coverage means more nearby dispatches
• Nearest Colleague Distance chart — orange bars = overlap avoided (agent chose order far from colleagues)
• Glass-Box "Avoided" column — 🔀 marks steps where collision avoidance changed the selection
• λ effect: λ=0 → same as V1 · λ=1 → strong avoidance, may ignore Q-values

⚠️ Limitations of V3

• No communication — agents observe positions but cannot share plans or intentions
• Greedy avoidance — agent avoids the nearest colleague but doesn't plan ahead
• λ tuning — too high λ ignores Q-values; too low λ = V1. No automatic tuning.
• Individual reward — credit assignment is still clear (same as V1), but no team incentive
• V4 (CTDE) will address these limitations with a centralised critic and full observability.

Task 1 — Distance-aware score

Agent $T_0$ considers order $W_3$. $Q^0(W_3) = 0.6$. Nearest colleague to $W_3$: $d_{\min} = 4.2$ km. $\lambda = 0.1$. Compute score$(T_0, W_3)$. Compare with $T_1$: $Q^1(W_3) = 0.8$, $d_{\min} = 1.1$ km. Which agent wins?

Under what two conditions does V3 behave identically to V1?

💡 Show answer
1. $\lambda = 0$: score$(t, o) = Q^t(o) + 0 = Q^t(o)$ — colleague distance has no effect.

2. During exploration ($\varepsilon$-greedy explore step): V3 uses the same random selection as V1 — distance-aware scoring only applies during exploitation.

🧠 V4 — CTDE (VDN) / Shared Reward / Full Observability

One sentence: A centralised coordinator has access to all agents' Q-tables and positions during training and selects the best technician using a joint Q-score (VDN decomposition) — while at execution time each agent still acts using only its own Q-table.

🧮 CTDE Paradigm

Centralised Training, Decentralised Execution (CTDE) is the dominant paradigm in modern MARL.

Training phase: A centralised critic/coordinator has access to the full global state — all agent positions, all Q-tables, all rewards. It uses this information to make better decisions and update all agents' Q-tables.

Execution phase: Each agent acts using only its own local Q-table $Q^i$, without any centralised coordinator. This makes the system scalable and robust to communication failures.
V1–V3 (Decentralised)
Training: each agent updates $Q^i$ independently
Execution: each agent uses $Q^i$ independently
No global information at any stage
V4 (CTDE)
Training: centralised coordinator uses all $Q^i$ + all positions
Execution: each agent uses $Q^i$ independently
Global information only during training

🧮 VDN Decomposition

Value Decomposition Networks (VDN) decompose the joint Q-function as a sum of individual Q-functions:
$$Q_{\text{joint}}(s, a^1, \ldots, a^n) = \sum_{i=1}^{n} Q^i(o^i)$$
This decomposition allows centralised training while keeping individual Q-tables for decentralised execution.

In our Warsaw ASP implementation:
• Selection: pick tech $t$ that maximises $Q^t(o) + 0.5 \cdot \text{dist\_bonus}(t, o)$
• Assigned agent update: full IQL update with $\alpha$
• All other agents update: soft update with $0.3\alpha$ — they learn from the joint experience even though they didn't act

🔄 What changes from V1 to V4

PropertyV1V4
Selection$\arg\max_t Q^t(o)$$\arg\max_t \left[Q^t(o) + 0.5 \cdot \text{dist\_bonus}(t,o)\right]$
Assigned agent update$Q^t \leftarrow Q^t + \alpha \cdot \delta$$Q^t \leftarrow Q^t + \alpha \cdot \delta$ (same)
Other agents updateNo update$Q^j \leftarrow Q^j + 0.3\alpha \cdot \delta^j$ for all $j \neq t$
ObservabilityNoneFull — all positions visible during training
RewardIndividual $R^i$Individual $R^i$ (VDN uses individual rewards)

📊 What to observe in V4

Expected behaviour vs V1–V3:
• More uniform Q-tables — all agents receive soft updates from every dispatch, not just their own
• Faster convergence — centralised training propagates information to all agents simultaneously
• Joint Q chart — $Q_{\text{joint}} = \sum Q^i(o)$ grows as agents learn; visible in the UI
• 🧠 CTDE label on map — marks exploit steps where centralised selection was used
• Lower avg distance — distance bonus in selection prefers nearby technicians

⚠️ Limitations of V4

• Simplified VDN — our implementation uses a heuristic distance bonus, not a full neural network critic
• Soft update weight (0.3α) is fixed — in full CTDE this would be learned
• No mixed reward — V5 will add individual + team bonus for better credit assignment
• Scalability — updating all agents at every step is $O(n)$ per step; full QMIX uses a mixing network

Task 2 — Soft update for non-assigned agent

$T_1$ is NOT assigned to $W_5$ (assigned to $T_3$). $Q^1(W_5) = 0.4$. Reward $R = 1.6$. $\max Q^1 = 0.9$. $\alpha = 0.1$, $\gamma = 0.95$. Compute new $Q^1(W_5)$ using soft update ($0.3\alpha$).

⚗️ V5 — CTDE / Mixed Reward / Partial Observability

One sentence: V5 combines the best of V3 and V4 — each agent receives a mixed reward blending individual and team signals, uses distance-aware selection (like V3), and benefits from centralised soft Q-updates (like V4).

🔄 What changes from V4 to V5

V4 — CTDE / Shared / Full

• Pure shared reward $\bar{R}$ for all agents
• Full observability: distance bonus in selection
• Soft Q-update for non-assigned agents
• Credit assignment still diluted (same as V2)
V5 — CTDE / Mixed / Partial

• Mixed reward: $\alpha_{ind} \cdot R^i + (1-\alpha_{ind}) \cdot \bar{R}$
• Partial observability: colleague distance in selection
• Soft Q-update for non-assigned agents (CTDE)
• Better credit assignment: individual component rewards good actions directly

🧮 Mixed Reward Formula

$$R_{mixed}^i = \alpha_{ind} \cdot R^i + (1 - \alpha_{ind}) \cdot \bar{R}$$
where:
$R^i$ = individual reward for agent $i$'s own dispatch
$\bar{R} = \frac{1}{n}\sum_{j=1}^{n} R^j$ = team mean reward
$\alpha_{ind} \in [0, 1]$ = individual reward weight (slider in UI)

Special cases:
• $\alpha_{ind} = 0.0$ → pure shared reward (identical to V2/V4)
• $\alpha_{ind} = 1.0$ → pure individual reward (identical to V1/V3)
• $\alpha_{ind} = 0.5$ → balanced (default) — best of both worlds

📊 V5 Selection Score

$$\text{score}(t, o) = Q^t[o] + \lambda \cdot d_{coll}(o) + 0.3 \cdot d_{bonus}(t, o)$$
where:
$Q^t[o]$ = agent $t$'s Q-value for order $o$
$\lambda \cdot d_{coll}(o)$ = colleague distance bonus (partial observability, like V3)
$0.3 \cdot d_{bonus}(t, o)$ = own distance bonus (CTDE component, like V4)

V5 combines both distance signals: avoid colleague overlap AND prefer nearby orders.

🧮 Q-Table Update in V5

Assigned agent (tech that served the order):
$$Q^i(o) \leftarrow Q^i(o) + \alpha \left[ R_{mixed}^i + \gamma \max_{o'} Q^i(o') - Q^i(o) \right]$$

Non-assigned agents (CTDE soft update with team signal):
$$Q^j(o) \leftarrow Q^j(o) + 0.3\alpha \left[ \bar{R} + \gamma \max_{o'} Q^j(o') - Q^j(o) \right] \quad \forall j \neq i$$

The $0.3\alpha$ factor ensures non-assigned agents learn more slowly — they did not directly experience this dispatch.

📊 What to observe in V5

Expected behaviour:
• Better credit assignment than V2/V4 — individual component rewards good actions directly
• Lower avg distance than V1/V2 — distance-aware selection avoids colleague overlap
• More uniform Q-tables than V1/V3 — CTDE soft updates propagate knowledge
• α_ind sensitivity: try 0.0, 0.5, 1.0 and compare learning curves
• Reward chart: shows 3 lines — individual $R^i$, team $\bar{R}$, mixed $R_{mixed}$

Task 1 — Mixed reward calculation

5 agents. Individual rewards: $R^0=+1.8,\; R^1=-0.5,\; R^2=+1.2,\; R^3=-1.0,\; R^4=+0.8$. $\alpha_{ind}=0.5$. Compute $R_{mixed}^0$ and $R_{mixed}^3$.

💡 Show answer
$$\bar{R} = \frac{1.8 + (-0.5) + 1.2 + (-1.0) + 0.8}{5} = \frac{2.3}{5} = 0.46$$
$$R_{mixed}^0 = 0.5 \times 1.8 + 0.5 \times 0.46 = 0.9 + 0.23 = \mathbf{1.13}$$

Task 2 — Why does V5 improve credit assignment vs V2?

Explain why $\alpha_{ind}=0.5$ gives better credit assignment than $\alpha_{ind}=0.0$ (pure shared).

💡 Show answer
With $\alpha_{ind}=0.0$ (pure shared), all agents receive $\bar{R}$ regardless of their individual action. A good action by $T_0$ is diluted by bad actions of other agents — $T_0$ is under-credited.

With $\alpha_{ind}=0.5$, the individual component $0.5 \cdot R^i$ ensures that $T_0$'s good action contributes directly to its Q-update. The team component $0.5 \cdot \bar{R}$ still encourages cooperation.

The higher $\alpha_{ind}$, the clearer the credit assignment — but the less cooperation incentive.

🌐 V6 — Cooperative MARL / Shared Reward / Full Observability

One sentence: All agents share a single cooperative Q-table updated by the team mean reward — the centralised coordinator picks the closest, most skilled technician for each order, making V6 the theoretical upper bound of cooperative performance in our MARL framework.

🔄 What changes from V5 to V6

V5 — CTDE / Mixed / Partial

• $n$ individual Q-tables $Q^i[order]$
• Mixed reward: $\alpha_{ind} R^i + (1-\alpha_{ind})\bar{R}$
• Soft updates for non-assigned agents
• Partial observability in selection
V6 — Cooperative / Shared / Full

• 1 shared cooperative Q-table $Q_{coop}[order]$
• Pure shared reward: $\bar{R}$ for all
• All agents update the same $Q_{coop}$
• Full observability: distance + skill bonus

🧮 Cooperative Q-Function

In V6, there is one shared Q-table for the entire team:

$$Q_{coop}[o] \leftarrow Q_{coop}[o] + \alpha \left[ \bar{R} + \gamma \max_{o'} Q_{coop}[o'] - Q_{coop}[o] \right]$$

Every dispatch updates the same $Q_{coop}$ — regardless of which technician served the order. This is the fully cooperative case: the team learns as a single entity.

🧮 V6 Selection Score

$$\text{score}(t, o) = Q_{coop}[o] + 0.5 \cdot d_{bonus}(t, o) + 0.5 \cdot \mathbb{1}[\text{skill match}(t, o)]$$
Since all agents share the same $Q_{coop}[o]$, the Q-value is identical for all technicians. The tiebreaker is:

• Distance bonus: prefer the technician closest to the order
• Skill bonus: +0.5 if technician skill matches order requirement

This means V6 always dispatches the closest, most skilled available technician — the globally optimal greedy choice given the learned $Q_{coop}$.

📊 What to observe in V6

Expected behaviour — upper bound:
• Highest mean $G_0$ — globally optimal greedy selection
• Fastest convergence — every dispatch updates the shared $Q_{coop}$, so learning is $n\times$ faster
• Most uniform per-agent curves — all agents share the same Q-table
• Cooperative Q chart — $Q_{coop}[o]$ grows as the team learns which orders are profitable
• Highest SLA rate — closest + skill-matched technician always selected
• Lowest avg distance — distance bonus ensures nearby technicians are preferred

⚠️ Limitations of V6

• Credit assignment is hardest — fully shared reward, no individual signal at all
• Not realistic — requires a centralised coordinator with full global state at all times
• Single point of failure — if the coordinator fails, all agents are blind
• Not scalable to partial observability — V6 requires full observability by design
• Upper bound, not practical — V5 is more realistic for real enterprise deployment

Task 1 — Cooperative Q update

$Q_{coop}(W_3) = 0.6$. Team dispatches $W_3$, team mean reward $\bar{R} = 1.4$. Next best $\max Q_{coop} = 1.1$. $\alpha=0.1$, $\gamma=0.95$. Compute new $Q_{coop}(W_3)$.

💡 Show answer
$$\delta = \bar{R} + \gamma \max Q_{coop} - Q_{coop}(W_3) = 1.4 + 0.95 \times 1.1 - 0.6 = 1.4 + 1.045 - 0.6 = 1.845$$
$$Q_{coop}(W_3) \leftarrow 0.6 + 0.1 \times 1.845 = \mathbf{0.785}$$
In V1, only the assigned agent would update its $Q^i(W_3)$. In V6, this single update benefits ALL agents — they all share $Q_{coop}$.

Task 2 — Why is V6 the upper bound?

Explain three reasons why V6 achieves the highest team performance in our MARL framework.

💡 Show answer
1. Fastest learning: Every dispatch updates $Q_{coop}$ — effectively $n$ agents contribute to every Q-update. V1 needs $n\times$ more episodes to accumulate the same experience.

2. Optimal selection: The closest, most skilled technician is always chosen (distance + skill bonus). No random assignment or suboptimal Q-value exploitation.

3. No coordination failure: In V1–V5, agents may independently choose suboptimal actions. In V6, the centralised coordinator always picks the globally best technician for each order.
