🎯 Czym jest Rozdział 02?

Programowanie Dynamiczne na MDP

Ch02 implementuje klasyczne algorytmy programowania dynamicznego (Bellman, 1957) dla MDP z pełną wiedzą o modelu. Agent nie eksploruje — oblicza optymalną politykę analitycznie przez iteracyjne rozwiązywanie układu równań Bellmana.

Analogia: zamiast uczyć się grać w szachy przez granie (Ch06+), Ch02 oblicza optymalną strategię przez analizę całego drzewa gry — możliwe tylko gdy znamy wszystkie reguły i prawdopodobieństwa.

Dwa algorytmy w Ch02

Value Iteration (VI)

  • Iteracyjnie stosuje operator Bellmana do V(s)
  • Zbiega do V*(s) gdy $\delta \to 0$
  • Prostszy, szybszy dla małych MDP
  • Polityka wyznaczana na końcu (greedy na V*)

Policy Iteration (PI)

  • Naprzemiennie: ocena polityki + poprawa polityki
  • Zbiega w skończonej liczbie kroków
  • Wolniejszy per iteracja, ale mniej iteracji
  • Polityka poprawiana w każdym kroku

📐 Teoria RL — Ramy Teoretyczne Ch02

Twierdzenie o optymalności Bellmana

Optymalna polityka $\pi^*$ spełnia zasadę optymalności Bellmana: każda podpolityka optymalnej polityki jest również optymalna.

Zasada optymalności Bellmana (1957)
$$V^*(s) = \max_a \sum_{s'} T(s,a,s') \left[ R(s,a) + \gamma V^*(s') \right]$$
Implementacja: bellman_optimality_operator() w ch02_bellman.rs

Funkcja wartości stanu V(s) i akcji Q(s,a)

Optymalna funkcja wartości stanu
$$V^*(s) = \max_a Q^*(s,a)$$
Optymalna funkcja wartości akcji (Q-funkcja)
$$Q^*(s,a) = \sum_{s'} T(s,a,s') \left[ R(s,a) + \gamma V^*(s') \right]$$
Związek: $V^*(s) = \max_a Q^*(s,a)$ i $Q^*(s,a) = R(s,a) + \gamma \sum_{s'} T(s,a,s') V^*(s')$

Optymalna polityka π*(s)

Polityka greedy na V* (deterministyczna)
$$\pi^*(s) = \arg\max_a \sum_{s'} T(s,a,s') \left[ R(s,a) + \gamma V^*(s') \right] = \arg\max_a Q^*(s,a)$$
W Ch02: polityka jest deterministyczna — dla każdego stanu istnieje jedna optymalna akcja.

Operator Bellmana i zbieżność

Operator Bellmana $\mathcal{T}$
$$(\mathcal{T} V)(s) = \max_a \sum_{s'} T(s,a,s') \left[ R(s,a) + \gamma V(s') \right]$$
Zbieżność Value Iteration
$$\| \mathcal{T} V - \mathcal{T} V' \|_\infty \leq \gamma \| V - V' \|_\infty$$
Operator Bellmana jest kontrakcją z współczynnikiem $\gamma < 1$. Gwarantuje zbieżność do jedynego punktu stałego $V^*$.

Kryterium stopu: $\delta = \max_s |V_{k+1}(s) - V_k(s)| < \theta$ gdzie $\theta$ to próg zbieżności (domyślnie $10^{-6}$).

🔢 Równanie Bellmana — Szczegóły

Intuicja — dlaczego równanie Bellmana działa?

Równanie Bellmana mówi: wartość stanu = najlepsza natychmiastowa nagroda + zdyskontowana wartość najlepszego następnego stanu. To rekurencja — wartość każdego stanu zależy od wartości sąsiednich stanów.

$$V^*(s) = \underbrace{\max_a}_{\text{wybierz najlepszą akcję}} \sum_{s'} T(s,a,s') \underbrace{\left[ R(s,a) + \gamma V^*(s') \right]}_{\text{nagroda teraz + wartość przyszłości}}$$

Konkretny przykład — Stan S3 w ASP

Stan S3: częściowa dostępność techników. Akcje: A0=przydziel_natychmiast, A1=czekaj, A2=eskaluj, A3=odrocz. $\gamma=0.95$

Obliczenie Q*(S3, a) dla każdej akcji
$$Q^*(S3, A0) = \sum_{s'} T(S3,A0,s') [R(S3,A0) + 0.95 \cdot V^*(s')]$$ $$Q^*(S3, A1) = \sum_{s'} T(S3,A1,s') [R(S3,A1) + 0.95 \cdot V^*(s')]$$ $$V^*(S3) = \max(Q^*(S3,A0),\; Q^*(S3,A1),\; Q^*(S3,A2),\; Q^*(S3,A3))$$ $$\pi^*(S3) = \arg\max_a Q^*(S3, a)$$

Macierz przejść T(s,a,s') — co to jest?

$T(s,a,s') = P(s'|s,a)$ — prawdopodobieństwo przejścia do stanu $s'$ po wykonaniu akcji $a$ w stanie $s$.

Warunek poprawności macierzy przejść
$$\forall s, a: \sum_{s'=0}^{7} T(s,a,s') = 1 \quad \text{i} \quad T(s,a,s') \geq 0$$
Weryfikacja: verify_transition_matrix() w ch02_bellman.rs — sprawdza sumę do 1 z tolerancją $10^{-6}$.

W Ch02 macierz T jest generowana deterministycznie z ziarna (seed) przez build_asp_transitions() — stochastyczna ale reprodukowalna.

Bellman Expectation vs Bellman Optimality

Bellman Expectation (dla danej polityki π)

$$V^\pi(s) = \sum_a \pi(a|s) \sum_{s'} T(s,a,s') [R + \gamma V^\pi(s')]$$
Używane w Policy Evaluation (krok 1 Policy Iteration)

Bellman Optimality (dla π*)

$$V^*(s) = \max_a \sum_{s'} T(s,a,s') [R + \gamma V^*(s')]$$
Używane w Value Iteration

⚙️ Algorytmy — Value Iteration i Policy Iteration

Value Iteration — pseudokod

Wejście: T(s,a,s'), R(s,a), gamma, theta (próg zbieżności) Wyjście: V*(s), pi*(s) Inicjalizacja: V(s) = 0 dla wszystkich s Powtarzaj: delta = 0 Dla każdego stanu s: v = V(s) ← zapamiętaj starą wartość V(s) = max_a Σ_s' T(s,a,s') [R(s,a) + γ·V(s')] ← operator Bellmana delta = max(delta, |v - V(s)|) ← śledź zmianę Dopóki delta >= theta ← kryterium stopu Wyznacz politykę: pi*(s) = argmax_a Σ_s' T(s,a,s') [R(s,a) + γ·V(s')]
Kryterium stopu
$$\delta_k = \max_s |V_{k+1}(s) - V_k(s)| < \theta \implies \|V_k - V^*\|_\infty < \frac{2\theta\gamma}{1-\gamma}$$

Policy Iteration — pseudokod

Wejście: T(s,a,s'), R(s,a), gamma Wyjście: V*(s), pi*(s) Inicjalizacja: pi(s) = losowa akcja dla wszystkich s Powtarzaj: ── Krok 1: Policy Evaluation ── Powtarzaj: delta = 0 Dla każdego stanu s: v = V(s) V(s) = Σ_s' T(s,pi(s),s') [R(s,pi(s)) + γ·V(s')] ← dla DANEJ polityki delta = max(delta, |v - V(s)|) Dopóki delta >= theta ── Krok 2: Policy Improvement ── policy_stable = True Dla każdego stanu s: old_action = pi(s) pi(s) = argmax_a Σ_s' T(s,a,s') [R(s,a) + γ·V(s')] ← greedy Jeśli old_action != pi(s): policy_stable = False Dopóki NIE policy_stable

Trzecia metoda: solve_exact() — rozwiązanie dokładne przez LU

Oprócz VI i PI, Ch02 zawiera dokładne rozwiązanie algebraiczne dla ustalonej polityki π:

Układ równań liniowych dla V^π
$$V^\pi = (I - \gamma P^\pi)^{-1} r^\pi$$
Implementacja: solve_exact() w ch02_bellman.rs — rozkład LU przez bibliotekę nalgebra.
Test: test_exact_solution_close_to_vi() weryfikuje że |V_VI − V_exact| < 0.5 dla każdego stanu.

Kiedy używać solve_exact()?

  • Gdy potrzebujemy dokładnej wartości V^π dla danej polityki
  • Weryfikacja poprawności Value Iteration
  • Małe MDP (|S| ≤ kilkaset) — LU jest O(|S|³)

Kiedy NIE używać?

  • Duże MDP — O(|S|³) jest prohibitywne
  • Gdy polityka się zmienia (trzeba rozwiązywać od nowa)
  • Online learning — brak modelu P^π

Złożoność obliczeniowa

Złożoność jednej iteracji Value Iteration
$$O(|S|^2 \cdot |A|) = O(8^2 \cdot 4) = O(256) \quad \text{(ASP Warszawa)}$$
W produkcji: $|S| = 10^6$, $|A| = 100$ → $O(10^{14})$ — niemożliwe bez aproksymacji (Deep RL).

To właśnie dlatego Ch02 działa tylko dla małych MDP z 8 stanami. Dla rzeczywistych problemów potrzebujemy sieci neuronowych (Ch15+).

Co oznaczają metryki KPI?

Iterations
Liczba iteracji do zbieżności ($\delta < \theta$). VI: typowo 100–500. PI: typowo 5–20 (ale każda iteracja droższa).
Max δ (final)
Maksymalna zmiana V(s) w ostatniej iteracji. Powinno być $< \theta$. Jeśli nie — zwiększ max iteracji.
V*(S0)
Wartość najlepszego stanu (wszyscy dostępni). Wyższe = lepszy MDP (wyższe nagrody lub wyższe γ).
V*(S7)
Wartość najgorszego stanu (naruszenie SLA). Zawsze ujemne lub najniższe — kara za SLA breach.
Policy changes (PI)
Tylko Policy Iteration: ile stanów zmieniło optymalną akcję w ostatnim kroku poprawy polityki. 0 = zbieżność.

Heatmapa Q*(s,a)

Tabela 8 stanów × 4 akcji. Każda komórka = $Q^*(s,a)$. Interpretacja:

  • Najjaśniejsza komórka w wierszu = optymalna akcja $\pi^*(s)$ dla tego stanu
  • Różnica między komórkami = jak bardzo jedna akcja jest lepsza od innej
  • Wiersz S7 = wszystkie wartości niskie/ujemne (stan kary)
  • Wiersz S0 = wszystkie wartości wysokie (stan nagrody)

Krzywa zbieżności δ

Wykres $\delta_k$ vs numer iteracji $k$. Kształt powinien być wykładniczo malejący:

$$\delta_k \leq \gamma^k \cdot \delta_0$$
Przy γ=0.95: po 100 iteracjach δ spada do $0.95^{100} \approx 0.006$ wartości początkowej. Przy γ=0.99: wolniejsza zbieżność.

Jeśli krzywa nie jest wykładnicza — sprawdź czy macierz T jest poprawna (sumuje się do 1).

Kluczowa obserwacja z Rozdziału 02

W Ch02 po raz pierwszy widzisz rosnącą krzywą V*(s) — wartości stanów zbiegają do optymalnych wartości. To fundamentalna różnica od Ch01 gdzie krzywa była płaska. Jednak Ch02 wymaga pełnej znajomości modelu T(s,a,s') — w prawdziwym świecie model jest nieznany. Dlatego od Ch05 przechodzimy do uczenia bez modelu: Monte Carlo (G_t z próbek) i TD Learning (δ online).

✏️ Ćwiczenia

Ćwiczenie 1 — Jeden krok Value Iteration

Stan S3. Akcje A0 i A1. $\gamma=0.95$. Dane:

  • $T(S3,A0,S0)=0.6$, $T(S3,A0,S7)=0.4$, $R(S3,A0)=+2$
  • $T(S3,A1,S1)=0.8$, $T(S3,A1,S3)=0.2$, $R(S3,A1)=+1$
  • $V(S0)=5.0$, $V(S1)=3.0$, $V(S3)=1.0$, $V(S7)=-5.0$

Oblicz Q(S3,A0), Q(S3,A1) i nowe V(S3).

▶ Pokaż rozwiązanie
$$Q(S3,A0) = 0.6 \cdot [2 + 0.95 \cdot 5.0] + 0.4 \cdot [2 + 0.95 \cdot (-5.0)]$$ $$= 0.6 \cdot 6.75 + 0.4 \cdot (-2.75) = 4.05 - 1.10 = +2.95$$ $$Q(S3,A1) = 0.8 \cdot [1 + 0.95 \cdot 3.0] + 0.2 \cdot [1 + 0.95 \cdot 1.0]$$ $$= 0.8 \cdot 3.85 + 0.2 \cdot 1.95 = 3.08 + 0.39 = +3.47$$ $$V_{new}(S3) = \max(2.95, 3.47) = +3.47 \quad \pi^*(S3) = A1$$

Ćwiczenie 2 — Zbieżność Value Iteration

$\gamma=0.9$, $\theta=0.01$. Po iteracji $k$: $\delta_k = 1.0$. Ile iteracji potrzeba do zbieżności?

▶ Pokaż rozwiązanie
$$\delta_k \leq \gamma^k \cdot \delta_0 \implies 0.9^k \cdot 1.0 < 0.01$$ $$k > \frac{\ln(0.01)}{\ln(0.9)} = \frac{-4.605}{-0.105} \approx 43.8 \implies k \geq 44 \text{ iteracji}$$
Przy γ=0.99: $k \geq 458$ iteracji. Wyższe γ = wolniejsza zbieżność.

Ćwiczenie 3 — Q* z V*

Dane: $V^*(S0)=8.2$, $V^*(S3)=3.1$, $V^*(S7)=-4.5$. Akcja A2 w stanie S1: $T(S1,A2,S0)=0.5$, $T(S1,A2,S3)=0.3$, $T(S1,A2,S7)=0.2$, $R(S1,A2)=+3$, $\gamma=0.95$.

Oblicz $Q^*(S1,A2)$.

▶ Pokaż rozwiązanie
$$Q^*(S1,A2) = \sum_{s'} T(S1,A2,s') [R(S1,A2) + \gamma V^*(s')]$$ $$= 0.5[3 + 0.95 \cdot 8.2] + 0.3[3 + 0.95 \cdot 3.1] + 0.2[3 + 0.95 \cdot (-4.5)]$$ $$= 0.5 \cdot 10.79 + 0.3 \cdot 5.945 + 0.2 \cdot (-1.275)$$ $$= 5.395 + 1.784 - 0.255 = +6.924$$

Ćwiczenie 4 — Policy Iteration krok po kroku

MDP z 2 stanami (S0, S1) i 2 akcjami (A0, A1). $\gamma=0.9$. Polityka startowa: $\pi(S0)=A0$, $\pi(S1)=A0$.

T(S0,A0,S0)=0.7, T(S0,A0,S1)=0.3, R(S0,A0)=+5 T(S0,A1,S0)=0.2, T(S0,A1,S1)=0.8, R(S0,A1)=+8 T(S1,A0,S0)=0.4, T(S1,A0,S1)=0.6, R(S1,A0)=-2 T(S1,A1,S0)=0.9, T(S1,A1,S1)=0.1, R(S1,A1)=+1

Wykonaj jeden krok Policy Evaluation (do zbieżności) i jeden krok Policy Improvement.

▶ Pokaż rozwiązanie
Policy Evaluation dla π=(A0,A0)
$$V(S0) = 0.7[5 + 0.9V(S0)] + 0.3[5 + 0.9V(S1)]$$ $$V(S1) = 0.4[-2 + 0.9V(S0)] + 0.6[-2 + 0.9V(S1)]$$
Rozwiązanie układu równań:
$$V(S0) = 5 + 0.9[0.7V(S0) + 0.3V(S1)] \implies V(S0) - 0.63V(S0) - 0.27V(S1) = 5$$ $$V(S1) = -2 + 0.9[0.4V(S0) + 0.6V(S1)] \implies -0.36V(S0) + 0.46V(S1) = -2$$ $$\implies V(S0) \approx +14.2, \quad V(S1) \approx +6.8$$
Policy Improvement:
$$Q(S0,A1) = 0.2[8+0.9\cdot14.2] + 0.8[8+0.9\cdot6.8] = 0.2\cdot20.78 + 0.8\cdot14.12 = 15.45 > V(S0)$$ $$\pi_{new}(S0) = A1 \quad \text{(zmiana polityki!)}$$
